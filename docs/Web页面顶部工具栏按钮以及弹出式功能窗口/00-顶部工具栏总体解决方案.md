# Web 页面顶部工具栏按钮以及弹出式功能窗口 — 总体解决方案

> 适用于管理端（9101）与用户端（29001）共用顶部工具栏（`ClientWeb/src/components/ToolbarDialogs.jsx` + `Layout.jsx`）。
> 补齐工程前后端功能缺口，完善顶部工具栏交互能力。

## 1. 现状与问题清单（调研结论）

| # | 问题 | 旧工程参照 | 修复方案 |
|---|------|-----------|---------|
| 1 | 「源码」按钮缺失（后端 `/SourceCodeInterface` 已实现但前端未接） | `server_web_common_dialog_sourcecode.go` | 新增 SourceCodeDialog：文件统计表 + 总计 + 查看 .go 源码内容 |
| 2 | README 读取路径错误：读 `config.GetConfigDir()/README.md`，实际 README 在工程根目录 | 旧读 `getProjectDir()/README.md` | 后端 `readmeInterfaceHandle` 改用 `system.GetProjectDir()` |
| 3 | 系统信息弹窗不自动刷新 | 旧 `setInterval` 定时刷新，关闭时停止 | SysDialog 增加 5s 自动刷新 + 开关 |
| 4 | Git 弹窗 commit 无文件变更展开 | 旧 `toggleCommitFiles`；后端 `changes` 字段已返回但前端未用 | 行点击展开/收起 `c.changes`（带 A/M/D/R 状态徽标） |
| 5 | 证书弹窗缺跨平台安装指引 | 旧含 Windows/macOS/Ubuntu/CentOS 安装步骤 | CertDialog 增加 `<details>` 折叠的分平台安装指引 |
| 6 | 弹窗无全屏能力 | 旧所有弹窗支持全屏按钮 + ESC | Modal 增加全屏切换按钮（`.modal-full` 类） |

## 2. 各弹窗 UI / 交互 / 美化统一规范

- **弹窗基座**：复用 `Modal.jsx`（遮罩点击关闭 + ESC 关闭），标题栏右侧「⛶ 全屏」按钮切换 `.modal-full`（100vw/100vh，内容区自适应滚动）。
- **视觉**：沿用现有暗色主题变量（`--panel` / `--muted` / `--accent`），列表统一 `data-table`，键值信息统一 `kv` 网格，日志统一 `log-box` 等宽字体。
- **加载态/空态**：统一 `table-loading` / `table-empty` / `alert-error` 提示。
- **用户端与管理端**：共用同一组件与接口，用户端经 `UserAuthMiddleware` 鉴权，无功能差异。

## 3. 各按钮明细

| 按钮 | 接口 | 弹窗内容 | 本次增强 |
|------|------|---------|---------|
| 用户日志 | POST `UserInfoLogInterface` | 关键词搜索 + 分页（100条/页）日志原文 | 保持现状 |
| Wiki | POST `WikiInterface` | .md 文件列表 → 内容查看（前端 Markdown 渲染） | 保持现状 |
| 证书 | GET `CertDownloadInfoInterface` / `CertDownloadInterface` | 代理地址、路径、证书状态/大小、下载按钮 | **新增** Windows/macOS/Ubuntu/CentOS 证书安装指引（折叠面板） |
| Git | GET `GitInfoInterface` | 分支/remote/commit 表格 | **新增** 行点击展开文件变更清单（A/M/D/R 状态色标：绿/黄/红/蓝） |
| 系统信息 | GET `SystemInfoInterface` | 主机/OS/CPU/内存/负载/磁盘 | **新增** 5 秒自动刷新开关（默认开） |
| README | GET `ReadmeInterface` | Markdown 渲染 | **修复** 后端改为读工程根目录 README.md |
| 构建日志 | GET `BuildTimeLogInterface` | 编译时间日志行 | 保持现状 |
| 源码（新增） | POST `SourceCodeInterface` | 源码统计（文件/行数/大小）+ 总计 | **新增** 前端按钮与弹窗；点击文件查看 .go 内容 |
| 退出 | POST `UserLogoutInterface` | 清凭据 + 回登录页 | 保持现状（`shared/auth.js`） |

## 4. 实施范围

- 后端：`ServerGo/api/server_api_common_info.go`（README 路径修复）。
- 前端：`ClientWeb/src/components/Modal.jsx`（全屏）、`ToolbarDialogs.jsx`（源码弹窗、系统刷新、Git 展开、证书指引）、`index.css`（`.modal-full`、变更状态徽标样式）。
- 验证：`./rebuild_restart_app.sh --build-only`（含前端构建）+ 接口实测 + `go vet`。

## 5. 图片资源

工具栏以文字按钮为主，暂不需要位图资源；如后续需要图标可由 `python-generate-image-tool` 生成（2048x2048 → `resize_image()` 缩放）。
