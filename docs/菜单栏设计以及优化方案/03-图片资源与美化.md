## 1. AI 生成图片资源

使用本地私有子工程 `python-generate-image-tool/`（火山引擎方舟 `doubao-seedream-5-0-pro-260628`）生成应用 Logo。

### 1.1 生成命令

```bash
cd python-generate-image-tool
python3 - <<'EOF'
from src import ArkImageGenerator, resize_image

gen = ArkImageGenerator()
# API 最小像素 3,686,400，先用 2048x2048 生成
p = gen.generate_and_save(
    prompt="极简扁平风格应用图标：字母 L 与令牌 token 环形组合，深蓝紫渐变背景，"
           "白色线条，现代科技 SaaS 仪表盘 logo，居中构图，无文字水印",
    size="2048x2048", watermark=False, filename_prefix="menu/app_logo")
# resize_image(input, output, (w, h)) 二次缩放到目标小尺寸
resize_image(p, "../ClientWeb/public/logo-128.png", (128, 128))
resize_image(p, "../ClientWeb/public/logo-48.png",  (48, 48))
resize_image(p, "../ClientWeb/public/logo-32.png",  (32, 32))
EOF
```

### 1.2 产出与用途

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `ClientWeb/public/logo-48.png` | 48×48 | 顶部 header 左侧 Logo（`h=26` 显示） |
| `ClientWeb/public/logo-32.png` | 32×32 | 侧栏折叠为图标栏时的顶部标识 |
| `ClientWeb/public/logo-128.png` | 128×128 | favicon / 登录页品牌图备用 |

原图保留在 `python-generate-image-tool/ImageOutput/menu/`（不入库）。

## 2. 美化要点（CSS）

| 部位 | 处理 |
|------|------|
| 分组标题行 | 13px 半粗体 + 分组图标 + 右侧 ▸/▾ 箭头（150ms 旋转过渡） |
| 二级项 | 左缩进 + 圆角 6px hover 浅灰底；激活态 `#e8f0fe` 底 + 左 3px 主色指示条 |
| 折叠提示 | 被折叠组内含当前页时，组标题右侧显示主色小圆点 |
| 整侧栏 | 200px ↔ 56px 宽度过渡 200ms；折叠态仅图标，`title` tooltip 兜底 |
| 头部 | header 左侧插入 Logo 圆形小图 + 标题，深色底上用浅色描边图 |
| 滚动 | 侧栏独立 `overflow-y: auto`，长列表不挤压主区 |

## 3. 图标约定

分组图标使用 emoji 符号（🏠 总览 / 👥 用户与路由 / 🧠 模型与代理 / 💬 对话分析 / 🕷 爬虫与数据 / 🧭 路由与模型），零依赖、跨端一致；后续若引入图标字体仅需替换 `navConfig.js` 中 `icon` 字段与 `SideNav` 渲染分支。
