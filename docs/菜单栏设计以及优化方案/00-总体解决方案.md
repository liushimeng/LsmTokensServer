# 00-菜单栏设计总体解决方案

> 适用对象：LsmTokensServer 管理员 Web 服务（9101）与用户 Web 服务（29001）共用的前端 `ClientWeb/`。
> 关联文档：[`01-菜单结构与交互设计.md`](01-菜单结构与交互设计.md)、[`02-实现说明与记忆方案.md`](02-实现说明与记忆方案.md)、[`03-图片资源与美化.md`](03-图片资源与美化.md)

## 1. 背景与现状问题

当前 `ClientWeb/src/components/Layout.jsx` 中，管理端 `ADMIN_NAV`（10 项）与用户端 `USER_NAV`（14 项）均为**扁平一级列表**，直接 `<a href="#/xxx">` 渲染，存在以下问题：

| # | 问题 | 根因 |
|---|------|------|
| P1 | 菜单无分级，14 项平铺，查找困难 | 无分组模型，只有 `[key, label]` 数组 |
| P2 | **点击乱串**：管理端从「用户管理」「路由管理」跳入 `ChatAnalysis*` / `ChatDialog` 后，侧边栏高亮全部丢失、页面失去菜单归属 | 这些分析页只存在于用户端菜单，管理端菜单缺失；`route === key` 精确匹配导致无项可亮 |
| P3 | 无折叠/展开能力，无法临时隐藏不常用分组 | 无分组概念、无折叠状态 |
| P4 | 无记忆功能，刷新/重进后分组折叠状态、侧栏展开状态全部复位 | 状态只存于 `useState`，未持久化 |
| P5 | 移动端抽屉式菜单与桌面端逻辑割裂 | `menuOpen` 与桌面侧栏是两套逻辑 |

## 2. 设计目标

1. **分级菜单**：一级为「功能分组」（可折叠），二级为「页面项」。管理端 5 组、用户端 4 组。
2. **消除乱串**：管理端补齐「对话分析」分组，并提供「路由 → 菜单项」映射表，任何页面都能定位到唯一菜单项高亮。
3. **折叠与隐藏**：一级分组支持折叠/展开；整侧栏支持折叠为图标栏（隐藏文字）；均即时生效。
4. **记忆功能**：分组折叠状态、侧栏折叠状态按角色分别持久化到 `localStorage`，刷新与重进自动恢复。
5. **美观美化**：统一的图标、分组标题样式、激活态指示条、平滑过渡动画；顶部栏与侧栏引入 AI 生成的应用 Logo。

## 3. 菜单结构设计（分级）

### 3.1 管理端（9101）

| 一级分组 | 二级页面项 | 说明 |
|----------|-----------|------|
| 总览 | 首页 | 系统信息总览 |
| 用户与路由 | 用户管理、端点管理、路由管理 | 用户/模型/端点/路由配置 |
| 模型与代理 | 模型信息、Agent信息、协议分析器 | 代理链路观测 |
| 对话分析 | 浏览记录、汇总统计、会话分析、任务分析、对话查看 | **新增**，修复 P2 乱串 |
| 爬虫与数据 | 爬虫数据源、爬虫日报、清理报告 | 数据采集与清理 |

### 3.2 用户端（29001）

| 一级分组 | 二级页面项 | 说明 |
|----------|-----------|------|
| 总览 | 首页 | 个人信息总览 |
| 对话分析 | 对话分析、汇总统计、会话分析、任务分析、对话查看 | 原 5 项归组 |
| 路由与模型 | 路由管理、模型信息、Agent信息、协议分析器、端点管理 | 只读观测 |
| 爬虫与数据 | 爬虫数据源、爬虫日报、清理报告 | 数据查看 |

### 3.3 页面 key 与菜单项映射

菜单项 key 与路由名一致；对「同页多入口」场景（如 `ChatAnalysis` 在用户端叫「对话分析」、管理端叫「浏览记录」），key 唯一、label 按角色定义，映射表按 key 匹配，天然消除歧义。

## 4. 交互设计

- **分组折叠**：点击一级分组标题行（含 ▸/▾ 箭头）切换该组折叠；仅折叠，不跳转。
- **页面跳转**：点击二级项跳转 `#/{key}`，同时关闭移动端抽屉。
- **侧栏折叠**：顶部 ☰ 按钮（桌面端）切换整侧栏为 56px 图标栏，悬停图标显示 tooltip；移动端 ☰ 仍为抽屉开关。
- **激活态**：当前路由对应二级项高亮（浅色底 + 左侧指示条）；其父分组自动展开（不改变用户已存的折叠态，仅本次展示临时展开）。
- **默认状态**：首次访问时，包含当前页的分组展开，其余分组管理端全展开、用户端展开「对话分析」。

## 5. 记忆方案（localStorage）

| Key | 内容 | 作用域 |
|-----|------|--------|
| `lsm.nav.collapsedGroups.admin` | JSON 数组，如 `["spider"]` | 管理端分组折叠 |
| `lsm.nav.collapsedGroups.user` | 同上 | 用户端分组折叠 |
| `lsm.nav.sidebarCollapsed` | `"1"` / `"0"` | 整侧栏折叠（两端共用） |

读写封装在 `shared/navConfig.js` 的 `loadNavState/saveNavState` 中，带 JSON 解析容错（损坏时回退默认值）。详见 [`02-实现说明与记忆方案.md`](02-实现说明与记忆方案.md)。
