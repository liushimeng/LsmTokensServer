## 2. navConfig.js 关键接口

```js
export const NAV_TREES = { admin: [...], user: [...] }

// 路由 → { groupId, itemKey }，由 NAV_TREES 构建，O(1) 查找
export const ROUTE_MAP = buildRouteMap(NAV_TREES)

// 记忆读写（带容错）
export function loadCollapsedGroups(role)  // → Set<string>
export function saveCollapsedGroups(role, set)
export function loadSidebarCollapsed()     // → boolean
export function saveSidebarCollapsed(v)
```

存储 key 约定：`lsm.nav.collapsedGroups.{role}`、`lsm.nav.sidebarCollapsed`，写入前 `JSON.stringify`，读取时 `try/catch + 类型校验`。

## 3. SideNav.jsx 组件逻辑

```jsx
<SideNav
  role={isAdmin ? 'admin' : 'user'}   // 决定菜单树与记忆 key
  route={route}                        // 当前路由（激活联动）
  collapsed={sidebarCollapsed}         // 整侧栏折叠（仅桌面）
  open={menuOpen}                      // 移动端抽屉开关
  onClose={() => setMenuOpen(false)}   // 抽屉关闭
/>
```

内部状态：
- `collapsedGroups: Set` —— 初始化 `loadCollapsedGroups(role)`，`role` 变化时重载。
- `overrideExpanded: Set` —— 激活项所在组的临时展开（渲染态，`collapsed − override` 才是实际折叠集）。
- 每次变更写回 `saveCollapsedGroups`。

激活解析：`ROUTE_MAP[route]` → `{ groupId, itemKey }`；未知路由返回 `null`，不高亮。

## 4. Layout.jsx 改造点

1. 删除 `ADMIN_NAV/USER_NAV` 平面数组与内联 `<nav>`，改为 `<SideNav/>`。
2. ☰ 按钮行为按视口分流：`window.matchMedia('(max-width: 860px)')` 监听，`true` → 抽屉开关；`false` → 侧栏折叠（写记忆）。
3. `layout-body` 加 `nav-collapsed` class 驱动 CSS 宽度过渡。
4. header 左侧加 `<img src="/logo-48.png">` Logo。

## 5. 测试与验证

- 前端无单测框架，本阶段以手工验证清单为准（编译后）：
  1. 管理端登录 → 菜单 5 组；用户端登录 → 菜单 4 组。
  2. 折叠「爬虫与数据」→ 刷新 → 仍折叠（记忆生效）。
  3. 折叠当前页所在组 → 自动临时展开，当前页可见且高亮。
  4. 管理端：用户管理 → 「浏览记录」→ 侧边栏「对话分析/浏览记录」高亮（乱串修复）。
  5. ☰ 折叠侧栏 → 56px 图标栏 → 刷新 → 保持。
  6. 窗口缩到 ≤860px → ☰ 变抽屉，点项后自动关闭。
- 后端 `go test ./...` 与 `go vet` 回归不受影响（纯前端改动），仍按规约执行。
