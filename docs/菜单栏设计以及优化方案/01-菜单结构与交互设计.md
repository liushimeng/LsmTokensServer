# 01-菜单结构与交互设计

> 上级文档：[`00-总体解决方案.md`](00-总体解决方案.md)

## 1. 数据结构

菜单用「树」描述，一级为分组（group），二级为页面项（item）：

```js
// shared/navConfig.js（节选）
{
  id: 'analysis',            // 分组 id（localStorage 记忆的最小单位）
  label: '对话分析',
  icon: '💬',
  items: [
    { key: 'ChatAnalysis',        label: '对话分析' },  // key = hash 路由名
    { key: 'ChatAnalysisTotal',   label: '汇总统计' },
    { key: 'ChatAnalysisSession', label: '会话分析' },
    { key: 'ChatAnalysisTask',    label: '任务分析' },
    { key: 'ChatDialog',          label: '对话查看' },
  ],
}
```

- `key` 全工程唯一，直接复用 `App.jsx` 的 `PAGES` 注册表键名，保证路由与菜单严格一致。
- 管理端与用户端各一棵 `NAV_TREE`，`Layout` 按 `userInfo.isAdmin` 选择。

| 分组 id | 分组名 | 页面 key | 管理端 | 用户端 |
|---------|--------|----------|:--:|:--:|
| overview | 总览 | Home | ✅ | ✅ |
| user-route | 用户与路由 | UserManage / DstEndPointManage / AIRouteManage | ✅ | — |
| model-proxy | 模型与代理 | ModelInfo / AgentInfo / ProtocolConvertAnalyzer | ✅ | — |

## 3. 交互规格

### 3.1 一级分组（group 行）

| 区域 | 行为 |
|------|------|
| 整行点击 | 折叠/展开该组（不跳转） |
| 箭头 ▸/▾ | 随状态旋转，过渡 150ms |
| hover | 浅灰底 `#f0f3f7` |

### 3.2 二级页面项（item 行）

| 状态 | 样式 |
|------|------|
| 默认 | 左侧缩进 12px，字色 `--text` |
| hover | 浅灰底 |
| 激活 | `#e8f0fe` 底 + `--primary` 字色加粗 + 左侧 3px 指示条 |
| 折叠后的组内激活项 | 组标题行右侧显示小圆点（提示当前页在被折叠的组里） |

### 3.3 侧栏整体折叠（桌面端）

- 宽度 `200px ↔ 56px`，过渡 200ms。
- 折叠后：仅显示图标；分组不可再折叠（点击图标即展开侧栏并定位）；页面项通过 `title` tooltip 展示名称。
- 顶部 ☰ 按钮在桌面端承担此功能；`@media ≤860px` 时 ☰ 回归移动端抽屉开关，侧栏折叠态不应用于抽屉。

### 3.4 激活联动规则

1. 路由变化 → 查映射表找到 item → 其父组若处于折叠态，**临时展开**（仅内存态，不写回 localStorage），保证当前页永远可见。
2. 用户手动折叠该组后才写回记忆；再次进入该组内页面时重复规则 1。

### 3.5 移动端（≤860px）

- 抽屉层 `position: fixed`，点遮罩或点页面项后关闭。
- 分组折叠交互与桌面端一致，记忆 key 共用。

## 4. 状态机

```
分组折叠态 collapsed = loadFromLS(role) ?? 默认值
路由变化:
  activeItem = findItem(route)
  if activeItem.group in collapsed:
      临时展开(override) → 渲染展开，但不改 collapsed
用户点击分组:
  collapsed = toggle(group) → saveToLS(role)
用户点击 ☰(桌面):
  sidebarCollapsed = !sidebarCollapsed → saveToLS
```

## 5. 边界与容错

- localStorage 不可用（隐私模式）→ 捕获异常，退化为纯内存态，功能不中断。
- 存储值 JSON 损坏 → 回退默认，并覆盖写回合法值。
- 未知路由（如服务端 redirect 别名 `UserLogin`）→ 映射表查不到则不高亮任何项，仅「总览」组保持展开。
- 角色未加载完成（`userInfo=null`）→ 先按用户端树渲染骨架，角色确定后切换，避免闪烁：角色探测结果已由 `App.jsx` 合并为单次 setState（阶段K 修复），闪烁窗口极小。
