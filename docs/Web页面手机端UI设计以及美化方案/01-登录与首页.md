# 01 - 登录与首页（Login / Home）

> 全局规范见 [00-总体设计方案与移动端规范](00-总体设计方案与移动端规范.md)，本文引用其章节号。

## 1. 页面定位与功能需求

- **Login（登录页）**：模型名称 + API Key + 图形验证码登录，支持记住凭证（本地加密存储）。核心诉求：手机上单手完成输入，验证码清晰可点。
- **Home（首页）**：展示登录用户信息（用户/模型/登录方式）与可用模型标签列表。纯展示页，是登录后的落地页。

## 2. 现状结构（简要）

### Login（`src/pages/Login.jsx`）
- 单列卡片表单：模型名称、API Key（带「显示/隐藏」切换）、验证码（输入框 + 可点击刷新图片）、记住凭证复选框、登录按钮。
- 深色渐变背景；卡片固定宽 380px。

### Home（`src/pages/Home.jsx`）
- `card-grid` 两卡：「登录信息」kv 列表；「可用模型（N）」tag 标签流。
- 无工具栏/表格/弹窗。

## 3. 手机端布局方案

### ≤860px
- Login 单列卡片天然适配；Home 卡片自动单列（00§3.3）。

### ≤600px
- Login 卡片宽度 `min(380px, 92vw)`、padding 28/22px（00§3.6）；
- 背景叠加 AI 生成图 `/login-mobile-bg.png` + 深色渐变遮罩（00§4）；
- 输入框 16px 字号防 iOS 聚焦放大（00§5）；验证码输入框与图片保持同行（field-inline），图片高 38px 不变；
- 登录按钮整行、高度 ≥40px。
- Home：两卡纵向堆叠，kv 键列收窄至 84px。

```
┌──────────────────┐
│  （深蓝渐变+AI背景） │
│  ┌────────────┐  │
│  │ LsmTokens…  │  │
│  │ 模型名称     │  │
│  │ API Key 显示 │  │
│  │ 验证码 [图]  │  │
│  │ ☑ 记住凭证   │  │
│  │ [  登 录  ]  │  │
│  └────────────┘  │
└──────────────────┘
```

## 4. 交互设计

- 验证码图片点击刷新保留，命中区 38px 高（可接受，输入行整体可点）。
- 登录失败自动刷新验证码逻辑不变；错误条整行展示。
- 登录成功 `hash → #/Home` + reload，移动端无差异。

## 5. 美观美化方案

- 登录页手机端使用 AI 生成深蓝科技渐变背景（1080×1920），卡片保持白底 + 大圆角 12px + 深阴影，与背景形成层次。
- Home 卡片沿用 00§4 的 10px 圆角 + 轻阴影移动端风格。
