# 06 - 协议转换分析器（ProtocolConvertAnalyzer）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)，本文引用其章节号。

## 1. 页面定位与功能需求

实验性 Anthropic↔OpenAI 协议转换工具：全局开关（仅管理端）、四段报文转换测试（输入/输出对照）、转换记录浏览与详情回放、字段映射知识库。核心诉求：手机上以「看记录、看映射表」为主，转换测试为低频操作。

## 2. 现状结构（简要）

文件：`src/pages/ProtocolConvertAnalyzer.jsx`。
- 状态卡：开关状态 + 启停按钮（管理端）+ 用户/模型统计。
- Tab 三枚：转换测试 / 转换记录 / 字段映射表。
- 记录 Tab：4 个筛选下拉 + 8 列表格（ID、时间、用户、模型、协议、URL 截 50 字、流式、操作-选择）+ 简易分页。
- 测试面板：方向下拉 + 流式复选 + 执行按钮；左右两栏 grid（`minmax(420px,1fr)`）各 4 个 log-box 文本框；MetricsPanel 深色进度条面板。
- 映射表 Tab：9 组「OpenAI tag ⟷ Anthropic tag + 备注」行。

## 3. 手机端布局方案

### ≤860px
- 记录表横向滚动（00§3.5 策略 1）；输入/输出双栏 grid auto-fit 自动降单列。

### ≤600px
- 记录表卡片模式（00§3.5）：ID + 协议作首行，"选择"按钮整行。
- **双栏 grid 防溢出**（页面级微调，已实施）：`minmax(420px,1fr)` → `minmax(min(420px,100%),1fr)`，360px 屏不再横向溢出。
- 4 个 textarea 纵向堆叠，log-box 限高 55vh（00§3.4 手机端规则）。
- Tab 三枚按钮整行排列（btn 高度 ≥40px，00§5）。
- 映射表每行「tag ⟷ tag + 备注」允许换行，tag 自动落到第二行。

```
┌──────────────┐
│[转换测试][记录][映射]│
├──────────────┤
│ 方向 ▼        │
│ ☑ 流式(SSE)   │
│ [  执行转换  ] │
├──────────────┤
│ 输入（4 个框）  │
│ 输出（4 个框）  │
│ MetricsPanel  │
└──────────────┘
```

## 4. 交互设计

- 选记录自动回填 4 个输入框 + 方向/流式设定：保留；手机上选记录后页面顶部出现提示条，用户手动滚回测试 Tab（不自动跳 Tab，避免跳动）。
- 执行转换并发 4 请求，各段独立报错：保留；错误红底 log-box 在窄屏整行展示。
- 角色探测（GET Toggle 405 判定）与手机端无关，不动。

## 5. 美观美化方案

- 沿用 00§4；MetricsPanel 深色面板保留，手机端进度条标签字号 12px。
- 映射表 tag 绿/橙配色保留，`⟷` 符号两侧留白收窄。
