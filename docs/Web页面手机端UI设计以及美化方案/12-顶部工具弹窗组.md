# 12 - 顶部工具弹窗组（用户日志/Wiki/证书/Git/源码/系统信息/README/构建日志）

> 组件：`ClientWeb/src/components/ToolbarDialogs.jsx` + `components/Modal.jsx`。
> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md) §3.1 / §3.4。

## 1. 功能需求

顶栏常驻 8 个工具入口，每个打开一个 Modal 弹窗：

| 按钮 | 内容形态 | 弹窗宽 |
|---|---|---|
| 用户日志 | 搜索工具栏 + 分页 + 等宽日志框 | 860 |
| Wiki | 文件列表表格 → Markdown 内容 | 860 |
| 证书 | kv 信息 + 下载按钮 + 跨平台安装指引（details 折叠） | 620 |
| Git | 提交表格（行可展开文件变更） | 760 |
| 源码 | 统计表格 → 文件内容日志框 | 860 |
| 系统信息 | kv 列表 + 5 秒自动刷新 | 720 |
| README | Markdown 渲染 | 860 |
| 构建日志 | 等宽日志框 | 760 |

## 2. 现状问题（手机端）

- 8 个文字按钮在深色顶栏一字排开，≤860px 必然溢出挤压 Logo 与「退出」按钮。
- 弹窗固定宽度 620~860px，手机（≤600px）全部横向溢出。
- 弹窗内表格（Wiki/源码/Git）列宽固定，窄屏可读性差。

## 3. 手机端布局方案

### 3.1 入口收纳（≤860px）

```
桌面端(>860)                     移动端(≤860)
┌──────────────────────────────┐  ┌──────────────────────┐
│☰ logo 标题 [管理端]  日 Wiki…│  │☰ logo [管理端]   ⋯ 退出│
└──────────────────────────────┘  └──────────────────────┘
                                       点击 ⋯ ↓
                                  ┌────────────┐
                                  │ 用户日志    │
                                  │ Wiki       │
                                  │ 证书       │
                                  │ …          │
                                  └────────────┘
```

- 「⋯」按钮仅 ≤860px 显示；点击展开深色顶栏下方的白色下拉面板（148px 宽、圆角 10px、阴影）。
- 面板内按钮竖排、深色文字、行高 44px 命中区。
- 点击遮罩或选中任一项后面板关闭。

### 3.2 弹窗（≤600px）

全部弹窗自动全屏（100dvh、圆角 0），等价于桌面端的「⛶ 全屏」态：
- 顶部标题栏保留（标题 + 全屏切换 + 关闭），关闭按钮命中区 40px；
- `.modal-foot` 按钮等宽拉伸（上一页/下一页等）；
- 弹窗内表格保留横向滚动（这些表格不走 DataTable 组件，不进入卡片模式）；
- 日志框 `.log-box` 限高 55vh、字号 11px。

## 4. 交互设计

- 「⋯」菜单与弹窗互斥：打开弹窗自动收起菜单（`useEffect` 联动）。
- 遮罩点击关闭沿用 Modal 现有行为；Esc 关闭桌面端保留。
- 系统信息弹窗 5 秒自动刷新在手机上不变，但 footer 复选框加大命中区。

## 5. 美观美化

- 下拉面板采用 `0 10px 30px rgba(15,23,42,.25)` 深阴影，与抽屉阴影体系一致。
- 「⋯」按钮 hover 背景与菜单 ☰ 按钮一致（`#374151`）。
- 弹窗全屏时内容区 padding 14px，标题栏下边线保留，视觉与原生 App 全屏页一致。
