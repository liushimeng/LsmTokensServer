## 2. 兼容性保证

- 所有移动端规则包在 `@media (max-width: …)` 内，**桌面端 >860px 样式零变化**。
- `DataTable` 默认卡片模式仅 ≤600px 生效；如某表格卡片模式不合适，传 `cardMode={false}` 退回横向滚动。
- 「⋯」下拉在 >860px 恒不显示（`.tools-more { display: none }` 默认）。
- 无新增 npm 依赖；无后端改动。
