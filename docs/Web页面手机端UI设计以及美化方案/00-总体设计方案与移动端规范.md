# 00 - 总体设计方案与移动端规范

> 适用范围：管理端 Web（9101）与用户端 Web（29001）共用的同一套 React SPA（`ClientWeb/`）。
> 本文是全局规范；各页面的专属方案见同目录 01~xx 文档。

## 1. 设计目标

1. **手机端可用**：375px（iPhone SE）~ 428px 宽度下所有页面可完整操作，无横向整页滚动。
2. **触控友好**：可点击元素命中区域 ≥ 40px；输入框字号 ≥ 16px（防 iOS 自动放大）。
3. **不破坏桌面端**：所有适配只在媒体查询断点内生效，桌面端像素级不变。
4. **无新依赖**：纯 CSS 媒体查询 + 少量组件结构微调，不引入 UI 框架。

## 2. 断点体系

| 断点 | 名称 | 主要行为 |
|---|---|---|
| `> 860px` | 桌面端 | 侧栏常驻（可整栏折叠为图标栏），布局不变 |
| `≤ 860px` | 平板/手机 | 侧栏变抽屉（已实现），工具栏按钮折叠进「⋯」菜单 |
| `≤ 600px` | 手机 | 弹窗全屏、表格转卡片、表单/工具栏全宽堆叠、字号微调 |

实现位置：`ClientWeb/src/index.css` 末尾的移动端区块；JS 侧断点判定统一用 `window.matchMedia('(max-width: 860px)')`（`Layout.jsx` 已有 `useIsMobile`）。

## 3. 全局布局策略

### 3.1 顶部栏（`.layout-header`）
- 高度保持 52px，`position: sticky`。
- ≤600px：隐藏 `.app-title` 长文本（保留 Logo + 角色徽标），`user-chip` 隐藏模型名只留用户名或整体收入「⋯」。
- 8 个工具弹窗按钮（用户日志/Wiki/证书/Git/源码/系统信息/README/构建日志）在 ≤860px 时收进一个「⋯」下拉面板，避免顶栏溢出。
- iOS 刘海：头部 padding 叠加 `env(safe-area-inset-top)`。

### 3.2 侧栏导航（`SideNav`）
- 已是抽屉式（≤860px），本方案增强：
  - 抽屉宽度 `min(280px, 78vw)`，菜单项行高加大到 44px 命中区；
  - 遮罩层加深并支持点击关闭（已有）；打开时禁止 body 滚动；
  - 路由切换后自动关闭抽屉（已有 `onClose`）。

### 3.3 主内容区（`.layout-main`）
- ≤860px：padding 20px → 12px（已有）。
- ≤600px：`.page-title` 20px → 18px；`.card` padding 16px → 12px；`.card-grid` 单列（`minmax(320px,1fr)` 在窄屏自动单列，无需改）。

### 3.4 弹窗（`Modal`）
- ≤600px：遮罩 padding 归零，弹窗全屏（宽 100vw、高 100dvh、圆角 0），等价于自动进入「全屏」态；顶部保留标题/全屏/关闭按钮。
- 底部 `.modal-foot` 按钮在手机上等宽拉伸（flex:1）。

### 3.5 数据表格（`DataTable`）
两种互补策略：
1. **≤860px**：保留横向滚动（`.table-wrap` 已有 `overflow-x:auto`），单元格 padding 收紧、字号 13→12.5px，滚动惯性 `-webkit-overflow-scrolling: touch`。
2. **≤600px**：默认切换为**卡片模式**——`DataTable` 渲染时为每个 `<td>` 写入 `data-label="<列名>"`，CSS 将行转为卡片：表头隐藏、每行一个圆角卡片、每格显示「列名 + 值」。操作列自动横向排列。
   - 个别列极多且以数字对比为主的表可通过 `cardMode={false}` 退出卡片模式，退回横向滚动。

### 3.6 表单与工具栏（`.toolbar` / `.field`）
- ≤600px：`.toolbar` 内 `input/select` 全部 `flex: 1 1 100%`（每行一个控件），按钮自动换行。
- 所有输入控件字号统一 16px（防 iOS 聚焦放大），高度 ≥ 40px。
- 登录页卡片 `width: 380px` → `width: min(380px, 92vw)`。

## 4. 视觉美化规范

- 沿用现有设计令牌（`--primary: #2563eb` 等 CSS 变量），不引入新色板。
- 移动端卡片阴影从轻边框改为 `0 1px 3px rgba(15,23,42,.06)` + 圆角 10px，更接近原生 App 观感。
- 抽屉/弹窗/下拉统一 150~200ms 过渡动画；尊重 `prefers-reduced-motion`。
- 点击反馈：去掉 `-webkit-tap-highlight-color` 蓝色闪光，按钮加 `:active` 缩放/变色态。
- 登录页手机端叠加 AI 生成的品牌背景图（`python-generate-image-tool` 生成，详见 01 文档）。

## 5. 触控与可访问性

- 命中区：导航项、工具栏按钮、表格操作按钮 ≥ 40×40px。
- 手势：不支持也不阻塞系统手势（边缘返回）；遮罩层 `touch-action: none` 防穿透滚动。
- `meta viewport` 已配置 `width=device-width, initial-scale=1.0`，保持不变。

## 6. 风险与回归点

- 桌面端 (>860px) 任何样式不得变化 —— 所有规则包在媒体查询内。
- 表格卡片模式依赖 `DataTable` 的 `data-label` 注入，需回归所有表格页（见 03~06 文档清单）。
- 「⋯」菜单与桌面按钮并存，需验证 ≥861px 时下拉不出现。
- WebSocket 流式页面（汇总统计/对话查看）在手机上以纵向堆叠为主，不砍功能。
