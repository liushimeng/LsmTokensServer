# 08 - 会话与任务分析（ChatAnalysisSession / ChatAnalysisTask）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)；本文引用其章节号，仅写页面差异。

## 1. 页面定位与功能需求

- **ChatAnalysisSession（会话分析）**：按 session 聚合对话（会话数/任务数/请求数/平均时长等 5 项指标）+ 会话明细表 + 会话详情弹窗。只读分析页。
- **ChatAnalysisTask（任务/工具调用分析）**：按 Task 预解析特征聚合（6 项指标 + 模型分布小表）+ 任务明细表 + 任务详情弹窗。只读分析页。
- 两页结构高度同构（同一套 toolbar / card-grid / DataTable / Modal / 前端切片分页），手机端方案一致，可合并实施。

## 2. 现状结构（简要）

### ChatAnalysisSession（`src/pages/ChatAnalysisSession.jsx`）
- 工具栏：用户名、模型名、时间跨度下拉、"分析"按钮（4 控件）。
- 卡片 5 张：总会话数、总任务数、总请求数、平均会话时长、平均任务数/会话。
- 表格 14 列：会话ID、开始/结束时间、时长(分)、请求数、任务数、输入/输出/总Tok、模型、流式、工具调用、来源地址、操作（详情）。
- 弹窗「会话详情」默认宽度，11 项 kv；前端切片分页（PAGE_SIZE=20）。

### ChatAnalysisTask（`src/pages/ChatAnalysisTask.jsx`）
- 工具栏同上 4 控件。
- 卡片 6 张：总任务数、流式/非流式、含系统提示词、含工具调用、平均耗时、平均消息数；另有「任务模型分布」2 列小表。
- 表格 15 列（全站最宽表）：ID、时间、任务模型、方法、URL(截 50 字)、状态(红绿)、消息数、用户消息、请求/响应大小、耗时、流式、工具调用、所属会话、操作（详情）。
- 弹窗「任务详情 #ID」kv 列表；前端切片分页。

## 3. 手机端布局方案

### ≤860px
- 工具栏 4 控件换行即可（全局 00§3.6），无页面级处理。
- 14/15 列大表横向滚动 + 密度收紧（全局 00§3.5 策略 1）；统计卡自动单列（00§3.3）。

### ≤600px
- 工具栏全宽堆叠（00§3.6）：4 行垂直排列，"分析"按钮整行。
- **两页主表均启用卡片模式**（00§3.5 策略 2）：
  - 会话表：会话 ID 作卡片首行加粗，开始/结束时间相邻两行，3 个 Tok 列与请求/任务数两两排列由 data-label 自然呈现，"详情"按钮整行。
  - 任务表：ID + 状态（红绿）作首行，URL 列允许整行换行（word-break），"详情"按钮整行。
  - 两表均以单条浏览为主，不设 `cardMode={false}`；数字对比需求由桌面横向滚动承担（00§3.5 已注明该选项）。
- 详情弹窗全屏（00§3.4），kv 单列堆叠；会话详情的「首条/末条 URL」长文本加 `word-break: break-all`。
- 统计卡：会话页 5 张、任务页 6 张，≤600px 采用 2 列网格（页面级微调，同 07 文档 KPI 处理），末张奇数卡占满整行。

│ ┌会话卡片───┐ │

## 4. 交互设计

- 只读页面，无增删改；唯一操作是"分析"查询与"详情"弹窗，触控按 00§5（≥40px）即可。
- 前端切片分页（PAGE_SIZE=20）在手机上保留，但分页器按钮整行加高至 40px；"共 N 个会话 / N 页"文字折行显示。
- 路由带 user_name/model_name 自动分析的逻辑保留（00§6 不砍功能）；手机上首次进入若未带参，空态文案提示"需填写用户名 + 模型名后分析"已在表格 empty 中，无需改动。
- 详情弹窗全屏后，kv 长值（URL、模型列表顿号串）允许换行；关闭按钮固定右上。
- 任务表"所属会话"当前为纯文本；手机端不新增跳转会话页的链接（避免本方案外的路由耦合，如需可在后续版本加 query 跳转）。

## 5. 美观美化方案

- 沿用 00§4 令牌与卡片样式；两页卡片数字字号 24px→20px（≤600px）。
- 会话/任务卡片首行 ID 用等宽字体 12px + `var(--muted)`，与正文区分层级。
- "流式/工具调用"的是/否、有/无值在卡片模式下加 `status-dot` 同款圆点，提升扫读效率。
- 任务页「任务模型分布」小表在卡片模式下仅 2 列，视觉上退化为列表，建议 ≤600px 直接隐藏表头行、按"模型名 — 数量"键值行展示（随卡片模式自然达成，无需代码）。
