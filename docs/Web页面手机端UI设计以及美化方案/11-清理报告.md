# 11 - 清理报告（CleanupReport）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)；本文引用其章节号。本页是仪表盘型只读页，含本方案中唯一手写柱状图与独立网格。

## 1. 页面定位与功能需求

展示过期数据自动清理的运行状态（启用/执行中/上次执行）、4 项累计 KPI、每日清理趋势柱状图、各分表空间占用网格（可对估算表执行精确计数）、清理明细表。核心诉求：手机上快速扫读"清理是否健康"，能下钻单表行数与明细记录。

## 2. 现状结构（简要）

文件：`src/pages/CleanupReport.jsx`。
- 工具栏：时间跨度下拉（7/30/90 天/无限制，localStorage 持久化）、刷新报告按钮、行内状态文字（status-dot + 文字）、保留天数文字。
- 4 张 KPI 卡：累计删除条数、累计释放磁盘、累计回收 Tokens、当前保留天数。
- 「每日清理趋势」：纯 div 柱状图（flex 等高 160px，渐变绿柱，title 悬浮明细，X 轴 MM-DD 标签 nowrap）。
- 「分表统计」：说明文字 + `grid: repeat(auto-fill, minmax(280px,1fr))` 卡片网格，每卡含表名、徽章（表缺失/≈估算/精确）、大号行数、数据/索引字节、时间范围、"精确计数"按钮、错误信息。
- 「清理明细」：12 列表（清理日期、分表索引徽章、分表名 code、删除条数、输入/输出/总 Tokens、释放空间、耗时、保留天数、过期判定时间、状态标签+错误消息），无操作列；分页器。

## 3. 手机端布局方案

### ≤860px
- 工具栏换行（00§3.6）；明细表横向滚动（00§3.5 策略 1）；KPI 卡与分表网格自动降列。

### ≤600px
- 工具栏全宽堆叠；状态文字与保留天数各占整行。
- KPI 卡 2×2 网格（页面级微调，同 07/08）。
- **趋势柱状图**（页面级重点）：数据点 ≤14 个时维持现状；超过时容器改横向滚动（`overflow-x:auto`，每柱 `min-width:18px`），日期标签保留 nowrap 不重叠；柱区高度 160px→120px。
- **分表网格**：`minmax(280px,1fr)` 在 <300px 屏宽溢出，按既定全局约定改为 `minmax(min(280px,100%),1fr)`（页面级微调，00§3.3 同款思路）。
- 明细表 12 列启用卡片模式（00§3.5 策略 2）：清理日期作首行，状态标签列置卡片顶部右侧；错误消息红字整行。
  - 注：本表数字列多，如有对比需求可 `cardMode={false}` 退回横向滚动（00§3.5 已提供该开关），默认仍卡片。

## 4. 交互设计

- 只读页，唯一主动操作是"精确计数"（单表 COUNT(*)，25s 超时回退近似值）：按钮在分表卡内 ≥40px（00§5），触发后 alert 反馈失败，保留原生 alert。
- 柱状图明细依赖 title 悬浮——**手机端无 hover**，页面级微调：点击柱子改为在该柱上方显示/切换同款文字（或把该日数据渲染到图下方一行文字区），保证触屏可读。
- 时间跨度切换即重载并写 localStorage：保留。
- 状态标签的"⏳ 自动重试中"提示在卡片模式下整行显示，title 文案无效，将"服务将自动重试"说明直接以小字展示（页面级微调）。

## 5. 美观美化方案

- 沿用 00§4 令牌；现状大量硬编码内联色（#d1fae5/#065f46 等徽章色）不在本期重构为令牌，仅做布局适配，避免 diff 失控。
- 趋势柱渐变色保留；≤600px 柱间距 gap 6px→4px。
- 分表卡徽章（表缺失/估算/精确）手机上保持 10px 字号徽章；大号行数 22px→18px。
- 明细卡片中"释放空间"保留蓝色加粗，作为视觉锚点。
