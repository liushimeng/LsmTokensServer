# 03 - 端点管理（DstEndPointManage）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)，本文引用其章节号。

## 1. 页面定位与功能需求

管理上游源站（平台/模型/协议/URL/API Key），支持批量启停/删除与连通性测试。核心诉求：手机上能完成源站的增改、启停与测试，长 URL 不撑破布局。

## 2. 现状结构（简要）

文件：`src/pages/DstEndPointManage.jsx`。
- 工具栏：刷新、+ 添加源站；勾选后追加：已选 N 条、批量启用、批量禁用、批量删除、取消选择。
- 表格 9 列：勾选、ID、所属用户、平台、模型、协议、URL（break-all）、状态、操作列 4 按钮（禁用/启用、编辑、测试、删除）。
- 弹窗 1「添加/编辑源站」（默认宽）：7 字段表单 + 深色 pre 请求头预览。
- 弹窗 2「连通性测试」宽 720：结果 alert + 请求/响应头体共 5 个等宽块。

## 3. 手机端布局方案

### ≤860px
- 表格横向滚动 + 密度收紧（00§3.5 策略 1）；工具栏自动换行。

### ≤600px
- 表格卡片模式（00§3.5）：平台/模型作首行，URL 整行 break-all，操作列 4 按钮自动横排换行。
- 工具栏勾选态的 6 个元素全宽堆叠（00§3.6），批量按钮整行。
- 两个弹窗全屏（00§3.4）：编辑表单 7 字段竖排；测试弹窗 5 个 pre 块纵向堆叠、各自限高 160px 可滚（现状已有）。

```
┌──────────────┐
│ [刷新][+添加源站]│
│ ┌源站卡片───┐ │
│ │ OpenAI    │ │
│ │ URL: https://…│
│ │ 状态: ● 启用 │ │
│ │ [禁用][编辑]  │ │
│ │ [测试][删除]  │ │
│ └───────────┘ │
```

## 4. 交互设计

- 批量操作上限 500 条 + confirm 保留；勾选框在卡片首行，命中区 ≥40px（00§5）。
- 连通性测试弹窗内 pre 块 `overflow-x: auto` 保留，长 JSON 横向滚动而非撑宽。
- 编辑弹窗 API Key 留空保持原值的提示文字整行换行显示。

## 5. 美观美化方案

- 沿用 00§4；URL 用 `var(--muted)` 12px 次要层级。
- 测试弹窗成功/失败 alert 全宽显示，等宽块字号 11px（00§3.4 log-box 手机端规则）。
