# 05 - 模型与 Agent 信息（ModelInfo / AgentInfo）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)，本文引用其章节号。两页结构完全对称，方案合并。

## 1. 页面定位与功能需求

全站报表页：按模型维度（ModelInfo）/ 按 AI Agent 工具维度（AgentInfo）统计 Token 与调用量。只读，核心诉求：手机上快速扫读 KPI、趋势与 Top 排名。

## 2. 现状结构（简要）

文件：`src/pages/ModelInfo.jsx`、`src/pages/AgentInfo.jsx`。
- 工具栏：时间跨度下拉（1~90 天/无限制，localStorage 持久化 + query 参数初始化）、刷新统计按钮、说明文字。
- 4 张统计卡（card-grid）：统计对象数、全站调用次数、全站 Tokens、输入/输出 Tokens。
- 「调用次数趋势」：纯 div 柱状图（flex 按比例高度 + 渐变色，title 悬浮提示，10px 日期标签）。
- 两张排名卡：Top 8 横向进度条（渐变填充 + 数值 + 百分比）。
- 明细表 9 列：排名、名称、调用次数/占比、输入/输出/总 Tokens、Token 占比、活跃用户。

## 3. 手机端布局方案

### ≤860px
- 明细表横向滚动（00§3.5 策略 1）；卡片自动降列（00§3.3）。

### ≤600px
- 4 张统计卡 2×2 网格（复用 `.kpi-grid`，见 07 文档同款模式）。
- 趋势柱状图：柱多时横向滚动（同 11 文档趋势图处理，`.trend-chart`/`.trend-bar` 复用）；点击柱子显示当日明细文字（替代 title 悬浮）。
- 进度条排名卡天然适配窄屏（flex 宽度百分比），无需改动。
- 明细表 9 列卡片模式（00§3.5）：模型名/Agent 名作首行，数字列成对展示。

```
┌──────┬───────┐
│模型数 │调用次数│
├──────┼───────┤
│总Tok │输入/输出│
├──────────────┤
│ 趋势 ▁▃█▇▃ →（可横滑）│
├──────────────┤
│ Top8 进度条     │
├──────────────┤
│ ┌明细卡片───┐ │
│ │ gpt-4o    │ │
│ │ 调用: 12,300│ │
│ └───────────┘ │
```

## 4. 交互设计

- 纯只读；时间跨度切换即重查，保留 localStorage 记忆。
- 柱状图 title 悬浮在手机上无效 → 点击柱子切换显示明细文字（同 11 文档方案）。

## 5. 美观美化方案

- 沿用 00§4；进度条渐变色保留。
- 统计卡数字 ≤600px 字号 26px→20px（随 `.kpi-grid` 卡片收紧）。
