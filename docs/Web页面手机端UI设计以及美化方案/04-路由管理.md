# 04 - 路由管理（AIRouteManage）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)，本文引用其章节号。本页为全站信息密度最高的页面。

## 1. 页面定位与功能需求

配置用户模型的智能路由：目标源站优先级列表（直连/转换器、排序、启停）、协议、算法策略（指定/稳定/经济），并查看时间跨度调用统计。核心诉求：手机上以「查看 + 跳转分析」为主，编辑路由为低频操作，可接受长表单滚动。

## 2. 现状结构（简要）

文件：`src/pages/AIRouteManage.jsx`。
- 工具栏：刷新、+ 添加路由；勾选后追加：已选 N 条、批量编辑算法（原生 prompt 输入 1/2/3）、批量删除、取消选择。
- 表格 11 列（全站最宽）：勾选、ID、用户、模型列表、目标源站列表（多标签）、协议、算法策略、时间跨度统计（表头内嵌下拉）、最后成功/失败记录（三行小字块）、操作列 5 控件（编辑 + 3 个分析跳转链接 + 删除）。
- 弹窗「添加/编辑路由」宽 760：用户→模型→协议三级级联下拉；已选源站列表每行 6 控件（2 单选 + 启停 + ↑↓ + 移除）；算法下拉 + 说明文字块。

## 3. 手机端布局方案

### ≤860px
- 表格横向滚动（00§3.5 策略 1）；该页建议 861~600 区间保留横向滚动浏览。

### ≤600px
- 表格卡片模式（00§3.5）：用户/模型作首行，目标源站标签流自动换行，最后成功/失败记录整行展示，操作列 5 控件自动换行为两行（编辑/删除一行，3 个分析链接一行）。
- 表头内嵌的时间跨度下拉在卡片模式下隐藏（表头整体隐藏），统计单元格以 data-label「时间跨度统计」呈现——**页面级微调**：在工具栏区增加一个独立的统计时间跨度下拉（仅 ≤600px 显示），或在卡片模式该列直接隐藏。本期采用后者（隐藏），保持简单。
- 编辑弹窗全屏（00§3.4）：三级级联下拉竖排；已选源站每行 6 控件改为两行布局（页面级 CSS：行容器 flex-wrap，单选组一行、按钮组一行）。

```
┌──────────────┐
│ ┌路由卡片───┐ │
│ │ user / gpt-4o│
│ │ 源站: ①平台A ②平台B│
│ │ 算法: 稳定型   │
│ │ [编辑][删除]   │
│ │ 对话 浏览 统计  │
│ └───────────┘ │
```

## 4. 交互设计

- 批量编辑算法的原生 `prompt()` 保留（系统弹层在手机上可用）；后续版本可改 Modal 三选一（见 13 文档已知取舍）。
- 分析跳转链接（对话/浏览/统计，带 query 参数）保留，手机上作为卡片底部链接行。
- 源站排序 ↑↓ 按钮在弹窗中加大命中区至 40px（00§5）。

## 5. 美观美化方案

- 沿用 00§4；禁用源站灰显 + 删除线保留，卡片模式下辨识度足够。
- 目标源站标签在卡片模式下间距 6px、自动换行，不再横向挤压。
