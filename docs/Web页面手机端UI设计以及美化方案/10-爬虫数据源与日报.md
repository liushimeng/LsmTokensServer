# 10 - 爬虫数据源与日报（SpiderDataSource / SpiderDailyInfo）

> 全局规范见 [00 文档](00-总体设计方案与移动端规范.md)；本文引用其章节号。

## 1. 页面定位与功能需求

- **SpiderDataSource（爬虫数据源管理）**：数据源 CRUD + 启停切换（删除仅管理端），每行可发起 AI 爬取——弹窗内编辑提示词，经 SSE 流式输出到日志框（最长 15 分钟）。核心诉求：手机上能编辑数据源、能盯着流式日志并随时关闭。
- **SpiderDailyInfo（每日 MCP 信息）**：按平台/时间范围分页浏览抓取资讯，行内按需展开全文（URL 自动转链接），支持单删/批量删。核心诉求：手机上以阅读为主，展开长文不撑破布局。

## 2. 现状结构（简要）

### SpiderDataSource（`src/pages/SpiderDataSource.jsx`）
- 工具栏：新增数据源、刷新按钮 + 提示文字。
- 表格 8 列：ID、平台名称、URL(外链)、源信息描述、备注、状态(圆点)、更新时间、操作列 **4 按钮并排**（爬取/编辑/禁用|启用/删除[仅管理端]）。
- 弹窗 1「新增/编辑数据源」：4 字段表单（平台名称*、URL*、描述 textarea 4 行、备注）。
- 弹窗 2「AI 爬取」固定 width=860：提示词 textarea 8 行 + `log-box` 日志框；SSE（openSse）增量输出。

### SpiderDailyInfo（`src/pages/SpiderDailyInfo.jsx`）
- 工具栏：平台下拉、开始/结束 datetime-local、重置、刷新、已选 N 条 + 批量删除。
- 卡片内表格 7 列：勾选、ID、平台、标题(外链)、爬取时间、内容（未加载/加载中/失败重试/已缓存/展开全文）、操作（展开|收起|重试 + 删除）。
- 分页器含每页下拉（1~100）；无弹窗（原生 confirm/alert）；路由 query 支持 page/page_size/platform/start_date/end_date。

## 3. 手机端布局方案

### ≤860px
- 两工具栏换行（00§3.6）；两表横向滚动收紧密度（00§3.5 策略 1）。

### ≤600px

**SpiderDataSource**：
- 表格卡片模式（00§3.5）：平台名称作首行，URL 整行可点；操作列 4 按钮自动横向排列（00§3.5 已含"操作列自动横向排列"），页面级微调为 **2×2 网格**（爬取/编辑/启停/删除），避免 4 按钮挤压。
- 编辑弹窗全屏（00§3.4），4 字段本身竖排 label.field，天然适配。
- 爬取弹窗全屏（00§3.4）：提示词 textarea 高度降为 5 行，log-box 占剩余高度（`flex:1`），底部按钮等宽拉伸（00§3.4 已有 modal-foot flex:1）。

```
┌────────────────┐
│ AI 爬取 — xxx  ✕│
├────────────────┤
│ 提示词 textarea  │
├────────────────┤
│ 爬取输出 log-box │
│ （SSE 流式追加，  │
│  纵向滚动）       │
├────────────────┤
│ [  关闭  ][开始爬取]│
└────────────────┘
```

**SpiderDailyInfo**：
- 表格卡片模式：标题作首行（外链），平台+爬取时间次之；**内容列展开时整行 pre-wrap 长文**（卡片模式下天然整行，正是该页在手机上优于桌面表格的点）；操作两按钮整行。
- 工具栏两个 datetime-local 全宽堆叠（00§3.6），原生控件占整行。
- 分页器：每页下拉 + 上下页按钮 ≥40px（00§5）。

## 4. 交互设计

- **SSE 流式（爬虫）**：功能不砍（00§6）。全屏弹窗内 log-box 自动滚到底部（追加文本后 `scrollTop = scrollHeight`，页面级微调）；爬取中"关闭"按钮禁用已有逻辑保留；弹窗打开期间禁止 body 滚动（00§3.4 全屏态附带）。
- **管理端判定**（UserManageInterface 探测 404）与删除 confirm：保留，手机端无差异。
- **批量删除（日报）**：卡片模式下每卡首行勾选框 ≥40px；"已选择 N 条 / 批量删除"在工具栏整行显示；原生 confirm 保留。
- **行内展开全文**：卡片模式下"展开内容"按钮整行；长文中的 URL 链接 `word-break: break-all` 保留；展开后整卡变高属预期。
- **路由 query 深链**（日报页 page/platform/日期）：保留，分享链接到手机可直接定位。

## 5. 美观美化方案

- 沿用 00§4。数据源表格 URL/描述列在卡片模式下用 `var(--muted)` 12px 次要层级。
- 爬取弹窗 log-box 用深色底（`#0f172a`）+ 等宽字体，贴近终端观感；[完成]/[错误] 行分别着 `var(--ok)`/`var(--danger)`（页面级微调，现为纯文本）。
- 日报内容展开区内链接色 `var(--primary)` 已有；行高 1.7 提升长文可读性。
- 状态圆点（启用/禁用）在卡片首行右侧展示。
