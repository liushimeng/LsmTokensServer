# 阶段2：后端基础模块迁移

## 迁移映射

| 旧文件 | 新位置 | 说明 |
|---|---|---|
| `server_conf.go` | `ServerGo/config/config.go` | 配置结构体与加载，改名为 LsmTokensServer |
| `server_logger.go` | `ServerGo/logger/logger.go` | 日志初始化（lumberjack 风格轮转） |
| `mysql_connect.go` | `ServerGo/database/connect.go` | GORM MySQL 连接 |
| `mysql_http_agent_sub_table.go` | `ServerGo/database/subtable.go` | 分表/分片 |
| `mysql_http_agent_*.go` | `ServerGo/models/` | 各业务数据层 |
| `mysql_http_ai_route_manage.go` 等 | `ServerGo/models/` | 路由/端点/用户/模型管理 |
| `main.go` | `ServerGo/main.go` | 入口重写（阶段2 仅做编译占位，阶段3 起接真实逻辑） |

## 实际调整（迁移过程中发现）
- `algorithm` 与 `models` 通过 `CachedAIRoute`/路由选择器互相依赖，强拆会产生循环依赖，
  故阶段2 将 `agent_algorithm*.go` 暂并入 `models` 包，待阶段3 代理层迁移后再评估拆分。
- `AgentProtocolType_*` 常量提取为叶子包 `protocol`，`recognizer`/`models` 共用。
- `logger` 拆分：DB 无关的日志基建留在 `logger` 包；`LogAIRouteAction`（依赖 models）迁至 `models/airoute_action_log.go`。
- `InitTestEnv` 测试基建迁至 `models/testutil_test.go`（SQLite 内存库）。
- 依赖 API handler 的统计类测试（agent_info_stats / model_info_stats 4 个文件）推迟至阶段3 随 API 层迁移。

## 注意
- 所有错误/日志文案中的 `LsmTokensServer` 改为 `LsmTokensServer`。
- 日志文件名、buildDateTime 日志名同步改名。
- 对应 `*_test.go` 随迁。

## 验收
- `go build ./...` 通过；`go test ./config/... ./database/... ./models/...` 通过（无需真实 DB 的用例）。
