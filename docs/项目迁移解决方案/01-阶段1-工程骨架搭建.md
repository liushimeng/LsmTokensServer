# 阶段1：工程骨架搭建

## 任务
1. 创建 `ServerGo/` Go 工程（module `github.com/lishimeng/LsmTokensServer`），先建立空 `main.go` + 目录骨架，保证 `go build` 通过。
2. 创建 `ClientWeb/`（React + Vite），空项目骨架，`npm run build` 通过。
3. 迁移并改写 `rebuild_restart_app.sh` 到 `scripts/`：
   - 程序名 `LsmTokensServer`、配置 `LsmTokensServer.conf`；
   - 支持前端 `npm ci && npm run build`（可选 `--skip-web` 跳过）；
   - 支持 `--build-only`（迁移期默认推荐，不启动不占端口）；
   - 部署 `ClientWeb/dist` 到后端静态目录。
4. `.gitignore`：忽略 conf、证书、日志、二进制、node_modules、dist 等。
5. 提供 `LsmTokensServer.conf.example`（脱敏模板）。
6. 迁移旧项目根目录 Markdown 与 `docs/` 到 `docs/`，改名改写（去掉 LsmHttpAgent 字样、修正路径 URL）。

## 旧→新文档映射（示例）
- `README.md` → 重写为开源版 `README.md`
- `AGENT.md`/`AGENT_INDEX.md`/`CLAUDE.md`/`KILO.md`/`SKILL.md`/`DEBUG_TOOL.md`/`Developer_SOP.md`/`CHANGELOG.md`/`MEMORY.md` → `docs/` 对应文件（评估是否开源需要，敏感内容删除）
- `MCP_*_def.md` → `docs/mcp/`
- `优化-20260730-01.md` → `docs/优化记录/`
- 旧 `docs/*.md` → `docs/`（cc-switch/Switchyard 协议分析系列）
