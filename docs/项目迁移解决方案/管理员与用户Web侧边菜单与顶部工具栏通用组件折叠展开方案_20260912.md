# 管理员与用户 Web 侧边菜单与顶部工具栏通用组件折叠展开方案

> 文档版本：v1.0 · 2026-09-12
> 适用版本：LsmTokensServer v2.0.77
> 关联代码：ClientWeb/src/components/Layout.jsx、SideNav.jsx、ToolbarDialogs.jsx、VersionInfo.jsx、shared/navConfig.js、shared/api.js、pages/Home.jsx
> 关联方案：docs/项目迁移解决方案/管理员与用户Web服务双构建隔离升级方案_20260825.md（角色 + 双构建隔离）

## 1. 现状摘要

### 1.1 现有实现

| 组件 | 文件 | 角色 |
|---|---|---|
| Layout（外层框架） | `components/Layout.jsx` | 装配顶栏 + 侧栏 + 主区；含 `navCollapsed`（桌面端整侧栏折叠）与 `menuOpen`（移动端抽屉开关） |
| SideNav（侧边菜单） | `components/SideNav.jsx` | 一级分组可折叠（`loadCollapsedGroups/saveCollapsedGroups` 按角色 localStorage 记忆），二级页面项点击切换；mini 模式下显示图标栏 |
| ToolbarDialogs（顶部工具按钮组） | `components/ToolbarDialogs.jsx` | 操作日志 / Wiki / 证书 / Git / 系统信息 / 构建日志 6 个按钮 + 「⋯」下拉（≤860px） |
| VersionInfo（版本信息） | `components/VersionInfo.jsx` | v2.0.77 + 后端构建时间 + 前端构建时间 |
| 菜单配置 + 记忆 | `shared/navConfig.js` | `NAV_TREES[role]` 一级→二级；`loadSidebarCollapsed/saveSidebarCollapsed` 整侧栏折叠记忆 |

### 1.2 已具备的折叠能力

- ✅ 整侧栏折叠（左侧 200px ↔ 56px 图标栏，localStorage `lsm.nav.sidebarCollapsed` 记忆）
- ✅ 一级分组折叠（每个分组可独立折叠/展开，localStorage `lsm.nav.collapsedGroups.<role>` 记忆）
- ✅ 移动端抽屉式开关（≤860px 自动切换为 fixed 抽屉）
- ✅ 顶部工具按钮移动端收进「⋯」下拉（≤860px）

### 1.3 已具备但不够细化/一致的体验

- ❌ 顶栏整体**无折叠**——图标、版本、角色徽章始终平铺；窄屏只是 hidden 文本，未折叠到下拉。
- ❌ 工具按钮在桌面端**永远平铺一行**——在 1024~1280px 中等宽度下与左侧菜单挤压内容。
- ❌ 侧栏折叠按钮只藏在 `☰` 菜单里——用户难发现"折叠整侧栏"入口。
- ❌ 顶栏操作日志/退出等业务按钮混排——缺少"主要操作"与"次要/管理类"按钮分组。
- ❌ 角色徽章在用户端可隐藏，在管理端固定——风格不统一。
- ❌ 用户端顶栏**没有"管理员端跳转"**——管理员跨端时只能改 URL，体验断裂。
- ❌ **未抽出"页面级通用"Header/Hero 区**——首页、对话分析、模型信息等页面的标题 + 工具栏各异，缺少统一容器（标题、面包屑、关键 KPI 占位、右侧 slot）。

### 1.4 设计目标

1. **完全通用**：Layout/SideNav/ToolbarDialogs/PageHeader 在管理端与用户端**同一套实现**，仅依赖 `__APP_ROLE__` + `NAV_TREES[role]` 配置差异化。
2. **折叠/展开行为统一**：所有可折叠元素都有明确入口 + localStorage 记忆 + 快捷键 + 平滑过渡。
3. **桌面 / 平板 / 手机三档自适应**：宽屏（≥1280px）平铺所有工具；中屏（860~1280px）折叠次要工具到下拉；窄屏（≤860px）整侧栏变抽屉 + 工具栏全部收进「⋯」。
4. **可发现性**：每个折叠/展开按钮都有 tooltip；折叠态在角落显示「已折叠」提示。
5. **键盘可达**：侧栏折叠、工具下拉都支持快捷键（`[`/`]`）。
6. **现有记忆平滑迁移**：复用 `lsm.nav.sidebarCollapsed` / `lsm.nav.collapsedGroups.<role>` 键值，老用户记忆不丢。

## 2. 设计方案

### 2.1 角色与构建隔离

继续保持 `__APP_ROLE__` 构建期常量 + Rollup 死代码消除：

- `__APP_ROLE__ === 'manager'`（管理端，9101）：菜单含 `UserManage`、`ManagerLogin`；顶栏显示「管理端」徽章；可显示「管理操作」分组。
- `__APP_ROLE__ === 'user'`（用户端，29001）：菜单不导出管理页；顶栏显示「用户端」徽章；只显示业务页跳转。

`NAV_TREES[role]` 已在 `shared/navConfig.js` 通过 `__APP_ROLE__ === 'manager'` 包裹 manager-only 树，构建后 user 产物不会包含管理菜单字样（构建后需 grep 复验）。

### 2.2 菜单栏（SideNav）折叠与展开

#### 2.2.1 三种折叠粒度

1. **整侧栏折叠**（`navCollapsed`）：200px ↔ 56px；记忆键 `lsm.nav.sidebarCollapsed`，桌面端记忆，移动端忽略。
2. **一级分组折叠**（`collapsedGroups: Set<groupId>`）：每个分组可独立折叠/展开；记忆键 `lsm.nav.collapsedGroups.<role>`。
3. **激活组临时展开**：当前激活路由所在分组即使被折叠也强制展开（不修改记忆），确保用户访问任何页都能看到自己在哪。

#### 2.2.2 折叠入口

| 入口 | 位置 | 触发 | 记忆 |
|---|---|---|---|
| 顶栏「☰」按钮 | 顶栏最左侧 | 桌面端折叠整侧栏；移动端打开抽屉 | `lsm.nav.sidebarCollapsed` |
| 一级分组标题 | 侧栏每个分组顶部 | 折叠/展开该分组（▸/▾） | `lsm.nav.collapsedGroups.<role>` |
| 侧栏 mini 模式下分组图标 | 56px 折叠态分组图标 | 点击图标展开整侧栏并定位到该分组 | 临时，不记忆 |
| 快捷键 `[` | 全局（输入框聚焦时禁用） | 切换整侧栏折叠 | 同 `navCollapsed` |
| 快捷键 `]` | 全局（输入框聚焦时禁用） | 切换所有一级分组的全折叠/全展开 | `lsm.nav.collapsedGroups.<role>` 全量覆盖 |

#### 2.2.3 mini 模式（56px）

- 仅显示每个一级分组的图标（`nav-group-icon`）。
- 当前激活分组图标高亮（`active` 样式）。
- 顶部 32px logo 占位。
- 鼠标悬停图标 → 显示该分组名称 tooltip（HTML `title` 属性）。

### 2.3 顶部工具栏（ToolbarDialogs）折叠与展开

#### 2.3.1 三档自适应布局

| 屏幕 | 行为 |
|---|---|
| ≥1280px（宽屏） | 所有按钮平铺（操作日志、Wiki、证书、Git、系统信息、构建日志） |
| 860~1279px（中屏） | 前 2 个高频按钮平铺，后 4 个收进「⋯」下拉（顺序按使用频率） |
| ≤860px（窄屏） | 全部收进「⋯」下拉面板 |

#### 2.3.2 顶栏额外按钮分组

按角色区分：

**管理员端**（`__APP_ROLE__ === 'manager'`）：
- **平台信息组**（平铺）：版本信息（v2.0.77 + 构建时间）
- **快捷操作组**（平铺 + ⋯）：操作日志、知识库（Wiki）、证书安装、Git 提交、系统信息、构建日志
- **管理员组**：管理员（用户名 chip）、退出

**用户端**：
- **平台信息组**（平铺）：版本信息
- **快捷操作组**（平铺 + ⋯）：知识库（Wiki）、证书安装、Git 提交（可选）、系统信息、构建日志（可选）
- **用户组**：用户名/模型名 chip、退出

#### 2.3.3 折叠入口

| 入口 | 位置 | 触发 |
|---|---|---|
| 「⋯」按钮 | 工具按钮组最右侧 | 打开次要按钮下拉面板（绝对定位，遮罩关闭） |
| 快捷键 `\` | 全局（输入框聚焦时禁用） | 切换工具栏「次要按钮下拉」开关 |
| 移动端「⋯」 | ≤860px 自动出现 | 打开全部工具按钮下拉面板 |

### 2.4 页面级 PageHeader 通用组件

新建 `components/PageHeader.jsx`，**所有页面**统一在主区顶部使用（替代各页面散落的 `<h2 className="page-title">`）：

#### 2.4.1 布局

```
┌─────────────────────────────────────────────────────────────────┐
│ 🏠  对话分析                                       [刷新] [导出] │
│      ChatAnalysis · /ChatAnalysis                              │
│      共 1,234 条记录 · 覆盖 30 天                              │
└─────────────────────────────────────────────────────────────────┘
```

- 左侧 slot：图标 + 主标题（i18n key）+ 面包屑（可选）
- 中间 slot：副信息（记录数 / 时间跨度 / 关键 KPI）
- 右侧 slot：页面级操作按钮（`刷新` / `导出` / `重置` 等）

#### 2.4.2 API

```jsx
<PageHeader
  icon="💬"                       // 一级分组图标（与 NAV_TREES 一致）
  titleKey="nav.chatAnalysis"     // i18n 标题键
  breadcrumb={['分析', '对话']}   // 可选面包屑
  info={[<KPI 文本 />, ...]}      // 可选 KPI 行
  actions={<>
    <button>刷新</button>
    <button>导出</button>
  </>}
>
  {children}                      // 页面内容（可作为 PageHeader 兄弟节点）
</PageHeader>
```

#### 2.4.3 已迁移页面（首期）

- `Home.jsx`（用户/管理员首页）
- `ChatAnalysis*.jsx`、`ChatDialog.jsx`、`ModelInfo`、`AgentInfo`、`AIRouteManage`、`DstEndPointManage`、`UserManage`、`ProtocolConvertAnalyzer`、`SpiderDataSource`、`SpiderDailyInfo`、`CleanupReport`

迁移策略：每个页面用一次 `git mv` + `Edit` 把 `<h2 className="page-title">` 替换为 `<PageHeader ...>`，保留 children。

### 2.5 顶栏整体折叠（中屏专属）

#### 2.5.1 顶栏分组结构

```
┌─ 左侧（header-left）────────────────────────────────┬─ 右侧（header-right） ─┐
│ ☰ | 🟦 LsmTokensServer v2.0.77 | 后端 09-10 10:41 │ 🇨🇳 [⋯]  管理员  退出 │
│   前端 09-10 10:41 | 🛡 管理端                       │                       │
└─────────────────────────────────────────────────────┴───────────────────────┘
```

#### 2.5.2 折叠模式（≤1024px 时启用）

- 「☰」按钮 + Logo + 版本号 保留在 header-left
- 「前端构建时间」「后端构建时间」「角色徽章」收进「⋯」下拉（顶栏右侧「⋯」与工具按钮「⋯」合并为一个面板，分组分隔）
- 语言切换始终保留
- 用户名/模型名 chip 在窄屏隐藏文本，仅显示头像首字符

### 2.6 快捷键

| 键 | 行为 | 作用域 |
|---|---|---|
| `[` | 切换整侧栏折叠 | 全局，输入框/可编辑元素聚焦时禁用 |
| `]` | 全部折叠 / 全部展开一级分组（toggle） | 全局，输入框聚焦时禁用 |
| `\` | 切换顶栏工具下拉 | 全局，输入框聚焦时禁用 |
| `?` | 打开快捷键帮助弹窗（首期可选实现） | 全局 |

`useKeyboardShortcut` 自定义 hook 统一管理，避免散落 addEventListener。

### 2.7 状态记忆键值表

| 键名 | 类型 | 作用 | 作用域 |
|---|---|---|---|
| `lsm.nav.sidebarCollapsed` | '0'/'1' | 整侧栏折叠 | 全局（管理员/用户共享同一标志，统一风格） |
| `lsm.nav.collapsedGroups.<role>` | JSON array<groupId> | 一级分组折叠集 | 按角色 |
| `lsm.toolbar.moreCollapsed` | '0'/'1'（新增） | 顶栏工具下拉是否已展开 | 全局（仅持久化"用户主动收起过"） |
| `lsm.header.timesHidden` | '0'/'1'（新增） | 用户主动收起过顶栏构建时间 | 全局 |
| `lsm.layout.shortcutsEnabled` | '0'/'1'（新增） | 是否启用快捷键（默认 1） | 全局 |

复用现有 `navConfig.js` 的 `safeGet/safeSet` 工具 + 容错，**不要**新建第三套 localStorage 访问层。

### 2.8 视觉与过渡

- 所有折叠/展开过渡：`transition: width .2s ease / opacity .15s ease`。
- 顶栏/侧栏颜色变量不变（沿用 `--panel`、`--border`、`--muted`）。
- 折叠按钮 hover：`background: #f0f3f7`（亮）/ `background: #374151`（顶栏深色按钮）。
- 当前激活分组在折叠时显示右下角小圆点 `.nav-active-dot`（已存在样式，复用）。

### 2.9 移动端适配

继续沿用现有 ≤860px 媒体查询策略：

- 整侧栏变抽屉（fixed 定位 + 遮罩）。
- 顶栏工具按钮全部收进「⋯」下拉。
- 顶栏分组构建时间、角色徽章 hidden。
- PageHeader 的右侧 actions 在 ≤600px 折叠到下拉（次要按钮自动溢出到「⋯」）。

## 5. 兼容性 & 风险

### 5.1 兼容性

- ✅ **不影响 API 层**：所有改动在 `components/` 与 `shared/navConfig.js` 内。
- ✅ **不影响数据契约**：纯 UI 折叠/展开，无新增接口。
- ✅ **不影响路由**：所有页面 key 与 `NAV_TREES[role]` 一致。

### 5.2 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 快捷键 `[`/`]`/`\` 误触 | 中等 | 输入框/可编辑元素聚焦时禁用 |
| localStorage 键冲突 | 低 | 沿用现有 `lsm.*` 命名空间 |
| 折叠/展开闪烁（首次渲染） | 低 | 状态用 `useState(loadSidebarCollapsed)` 同步初始化，避免首帧未折叠 |
| mini 模式 tooltip 与中文 i18n 不一致 | 低 | 复用 `t(g.label)` |
| PageHeader 改动 13 个页面 diff 较大 | 中 | 用 `replace_all` 批量替换 `<h2 className="page-title">{t(...)}</h2>` 为 `<PageHeader ...>`，每个页面单独 Edit |

### 5.3 回滚策略

- 所有改动集中在 `ClientWeb/src/components/*` + `ClientWeb/src/shared/*` + `ClientWeb/src/pages/*` 顶部。
- 若发现体验回归，revert 单文件即可，不影响其他模块。
- localStorage 键值新增但不影响老值；老用户记忆键 `lsm.nav.sidebarCollapsed` / `lsm.nav.collapsedGroups.<role>` 复用。
