# 阶段6：测试迁移与服务切换

## 测试迁移
- 旧 `v20xx_*_test.go`、`test_*_test.go`、`*_test.go` 按被测模块归入 `ServerGo/` 各包。
- 需要真实 MySQL/Chrome 的用例标记 build tag 或 `testing.Short()` 跳过，保证 CI 可离线运行。

## 切换流程（必须人工确认后执行）
1. `cd ClientWeb && npm run build`；`cd ServerGo && go build`；`go test ./...` 全绿。
2. 确认 `LsmTokensServer.conf` 端口与旧一致（9101/29000/29001/29002/29003）。
3. 人工核实清单：登录/管理端首页/用户端首页/代理转发/MCP/爬虫开关关闭/cleanup 关闭。
4. 执行 `./scripts/rebuild_restart_app.sh`：停旧进程 → 起新进程 → 验证端口。
5. 旧 `/usr/local/LsmHttpAgent` 目录与二进制保留 ≥30 天作为回滚手段。

## 回滚
- 新服务异常：`./scripts/rebuild_restart_app.sh --stop-new` 停新；回旧目录执行旧 `rebuild_restart_app.sh` 重启旧服务。

## 旧目录不迁移内容（留在原地）
- 巨型日志（.1/.2/.3.log）、二进制、pid、证书私钥、`.git`、`.claude`、`.kilo`、`.vscode`、`go-web-debug-tool`（submodule）、问题分析报告类临时 md。
