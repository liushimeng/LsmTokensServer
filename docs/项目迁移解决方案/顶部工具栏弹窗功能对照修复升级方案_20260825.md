## 2. 修复项明细

### 2.1 Wiki get_content 路径校验前缀碰撞（安全）
- 旧程序与当前迁移版均用 `strings.HasPrefix(absPath, absProjectDir)`（extra.go wiki 分支无分隔符），项目目录 `/usr/local/LsmTokensServer/LsmTokensServer` 与 `/usr/local/LsmTokensServer/LsmTokensServerX/a.md` 前缀碰撞可绕过。
- 修复：统一抽出 `safeProjectFilePath(projectDir, relPath, ext)` 工具（common_info.go），规则：
  1. 后缀必须是 `ext`（.md / .go）；
  2. `filepath.Rel(projectDir, abs)` 计算，`rel` 以 `..` 开头或为绝对路径即拒绝（彻底消除前缀碰撞）；
  3. 必须是普通文件且 < 5MB。
- Wiki / 源码 get_content 分支统一走该函数。

### 2.2 Git 接口 N+1 子进程 + 全量提交（性能）
- 旧程序与当前版 `GetGitRepoInfo(0)`：`git log` 全量提交 + 对**每个提交**再 fork 一次 `git show --name-status`（数百提交 = 数百次 fork/exec，一次性阻塞）。
- 重构：
  - `system` 新增 `GetGitRepoInfoLight(maxCommits)`：`git log -N --pretty` 一次拿提交列表（不带文件变更）；总数用 `git rev-list --count HEAD` 单次查询；不执行任何 `git show`。
  - `system` 新增 `GetGitCommitChanges(hash)` 导出（复用现有 `getCommitFileChangesWithDir`）。
  - `GitInfoInterface` 支持 GET 查询参数：`limit`（默认 100，上限 500，≤0 时 100）与 `action=get_changes&hash=xxx`（hash 校验 `^[0-9a-f]{6,40}$`，惰性返回单提交文件变更）。
- 前端 `GitDialog`：提交列表每页 20 条客户端分页（对齐旧程序）；点击行展开时**才**调用 `get_changes` 并本地缓存，弹窗打开零 `git show` 子进程。

### 2.3 证书弹窗补齐 HTTPS 接入地址（功能回归）
- 旧程序展示 Anthropic / OpenAI 完整接入 URL 并带复制按钮，迁移版只展示裸字段。
- 前端拼装 `https://{agent_host}:{https_port}/{anthropic_path}` 与 `.../{openai_path}`，一行一个「复制」按钮（`navigator.clipboard`，降级 `document.execCommand`）；HTTPS 未启用时整块置灰提示。

### 2.4 源码弹窗补齐文件名过滤（功能回归）
- 旧程序左侧文件表带过滤输入框。前端 `SourceCodeDialog` 顶部加 `filter` state，前端过滤 `(stats.files||[]).filter(f => f.name.includes(filter))`，并显示 `N / 总数`。

### 2.5 系统信息弹窗补齐分区（功能回归）
- 后端 `SystemInfo` 早已返回 `disk_io` / `process` / `network` / `process_tops`，前端只渲染了基本分区。
- `SysDialog` 增补（全部只读展示，不新增后端改动）：
  - 磁盘 IO：读/写速率、IOPS、iowait；
  - 本进程：PID、线程数、FD 数、RSS；
  - 网络：TCP 连接数、监听端口（前 8 个）；
  - Top 进程：CPU 前八（PID/名称/使用率）。

### 2.6 已确认无需重复修复（旧程序缺陷在新架构已消除）
- 旧程序 8 个接口**未登录可访问**（Git 历史 / 源码全文 / 系统信息 / 用户日志全暴露）：新架构用户端整 mux 套 `UserAuthMiddleware`、管理端套 `ManagerAuthMiddleware`，已修复。
- 旧程序共享 `buildtime-*` DOM 切换易样式错乱：React 组件化已消除。
- 旧程序 README/Git 依赖二进制目录恰好为仓库根：`GetProjectDir()` 回退逻辑已在阶段 L 处理。
