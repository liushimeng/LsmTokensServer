## API 契约约定
- REST 接口路径与响应结构保持与旧版一致（前端阶段按旧接口逐页对接），便于回滚与联调。
- `server_web_*.go` 中的 HTML/JS/CSS 生成代码**不迁移**，改为前端实现；但其中的业务数据组装逻辑提取为 API。
