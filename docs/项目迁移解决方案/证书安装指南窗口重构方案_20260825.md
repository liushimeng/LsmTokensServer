# 证书安装指南窗口重构方案（阶段AI，2026-08-25）

> 背景：管理端/用户端 Web 顶部工具栏"证书"按钮及其弹出窗口已在阶段 L 迁移至前后端分离架构
>（`ClientWeb/src/components/ToolbarDialogs.jsx` 中的 `CertDialog` + `ServerGo/api/server_api_common_extra.go` 中
>的 `/CertDownloadInfoInterface` / `/CertDownloadInterface`）。阶段 AA 已补齐 HTTPS 接入地址与复制按钮。
> 但当前弹窗仍存在以下不足：
>
> 1. **接入地址缺失 HTTP 版本**：实际部署中用户既能用 HTTPS（`29003`）也能用 HTTP（`29000`），现弹窗只展示 HTTPS 一组；
> 2. **对接入主机的处理有歧义**：当前 `agentProductListenAddr="0.0.0.0"` 是监听地址，不能直接作为对外接入地址使用；
>    用户拿不到真实公网/内网 IP（如 `8.130.85.252`），复制出来的接入地址不能直连；
> 3. **跨平台安装指引覆盖不全**：只有 Windows / macOS / Ubuntu / CentOS 四段，缺"通用 Linux"和"Fedora / Arch"等
>    常见发行版，命令不统一；
> 4. **指引内容排版粗糙**：当前 `<ol><li>` 行内堆叠，没有区块标题、没有"下载证书 → 验证安装 → 客户端配置"的三段式，
>    没有 icon、没有"复制全部命令"按钮；
> 5. **缺少证书文件元信息**：未展示证书 Subject / Issuer / 有效期 / SHA-256 指纹 —— 用户拿到 .crt 后不知道该信任的是不是当前服务；
> 6. **Modal 标题与按钮文案不符**：按钮叫"证书"，弹窗叫"HTTPS 证书下载"，语义模糊，缺统一标题"证书安装指南"；
> 7. **管理员/用户 Web 双构建隔离**：本次重构同样需保证 `dist-user` 不引入管理员专属代码。
>
> 本方案对照旧程序 `/usr/local/LsmHttpAgent/`（旧 Web 端写在 Go 文件中）做出统一升级。

## 2. 重构目标

1. **完整接入地址**：4 条 URL 一屏全展示（HTTPS Anthropic / OpenAI + HTTP Anthropic / OpenAI），每条独立"复制"按钮，
   标题分组"🔒 HTTPS（推荐）"与"🌐 HTTP"两组；
2. **真实公网/内网 IP**：新增 `agentPublicHost` 配置项（独立于 `agentProductListenAddr`），优先作为接入地址主机，
   旧字段空时仍回退旧逻辑；
3. **证书元信息**：解析 `server.crt` 返回 Subject / Issuer / NotBefore / NotAfter / SHA-256 指纹 / 序列号，
   前端用 4 行 `.kv` 展示，过期/未过期状态高亮；
4. **跨平台安装指引**：
   - **macOS** —— 钥匙串访问（GUI）+ `security add-trusted-cert`（CLI）双路径
   - **Windows** —— `certlm.msc` 受信任根证书颁发机构 + PowerShell `Import-Certificate`（管理员）
   - **Ubuntu / Debian** —— `ca-certificates` 包 + `update-ca-certificates`
   - **CentOS / RHEL / Rocky / Alma** —— `ca-trust` + `update-ca-trust`
   - **Fedora** —— 与 RHEL 同（`/etc/pki/ca-trust/source/anchors/`）
   - **Arch / Manjaro** —— `trust anchor`（新版 nss-tools）
   - **通用 Linux（snap/flatpak 等）** —— 提示用户用以上任一发行版的命令，或直接让浏览器/curl 信任
   - 每个段落都拆成「下载 → 安装 → 验证 → 客户端配置」四步，每步旁有"📋 复制"按钮；
5. **Modal 标题**：统一改为"证书安装指南"；宽度由 620 → 760 容纳新分区；
6. **UI 美化**：每个系统段落用 `.guide-section`（带左侧色条 + 系统图标 + 折叠展开），与现有 `.guide details/summary`
   视觉对齐但不重叠；命令代码块可一键复制；
7. **零管理端代码污染 dist-user**：所有管理员/用户共用部分均通过 `__APP_ROLE__` 静态门控已注册，新版仅修改文案与结构，
   不引入管理员专属组件。

## 4. 接口契约（前后端对齐）

### 4.1 新增 / 调整字段

```go
type CertDownloadInfoResponse struct {

    OpenAIPath     string `json:"openai_path"`

    // 新增字段

    HttpPort        int    `json:"http_port"`          // 29000
    PublicAnthropicURL string `json:"public_anthropic_url"` // https://{public_host}:29003/Anthropic
    PublicOpenAIURL    string `json:"public_openai_url"`    // https://{public_host}:29003/OpenAI
    HttpAnthropicURL   string `json:"http_anthropic_url"`   // http://{public_host}:29000/Anthropic
    HttpOpenAIURL      string `json:"http_openai_url"`      // http://{public_host}:29000/OpenAI
    CertSubject     string `json:"cert_subject"`       // CN=...,O=...
    CertIssuer      string `json:"cert_issuer"`
    CertNotBefore   string `json:"cert_not_before"`    // RFC3339
    CertNotAfter    string `json:"cert_not_after"`     // RFC3339
    CertSHA256      string `json:"cert_sha256"`        // 十六进制大写 + 冒号分隔
    CertSerial      string `json:"cert_serial"`        // 十六进制大写
    CertExpired     bool   `json:"cert_expired"`       // true=已过期 / 未生效
}
```

### 4.2 接入地址构造规则（前端构造即可，但后端直接返回减少前端拼装）

```
public_anthropic_url  = https://{PublicHost}{:{HttpsPort}}/{AnthropicPath}
public_openai_url     = https://{PublicHost}{:{HttpsPort}}/{OpenAIPath}
http_anthropic_url    = http://{PublicHost}{:{HttpPort}}/{AnthropicPath}
http_openai_url       = http://{PublicHost}{:{HttpPort}}/{OpenAIPath}
```

- `HttpsPort == 0` 或 `PublicHost == ""` → 对应 `*_url` 返回空字符串，前端置灰显示；
- `HttpPort == 0` → HTTP 组整组隐藏；
- 端口 = 80/443 → URL 省略 `:port`（与现有逻辑保持一致）；

### 4.3 证书元信息解析（`parseCertMeta`）

```go
func parseCertMeta(certPath string) (subject, issuer, notBefore, notAfter, sha256, serial string, expired bool) {
    data, err := os.ReadFile(certPath)
    if err != nil { return }
    block, _ := pem.Decode(data)
    if block == nil { return }
    cert, err := x509.ParseCertificate(block.Bytes)
    if err != nil { return }
    subject = cert.Subject.String()
    issuer = cert.Issuer.String()
    notBefore = cert.NotBefore.UTC().Format(time.RFC3339)
    notAfter = cert.NotAfter.UTC().Format(time.RFC3339)
    sum := sha256.Sum256(cert.Raw)
    sha256 = strings.ToUpper(hex.EncodeToString(sum[:]))
    // 按 8 字节一组加冒号，与 OpenSSL `openssl x509 -fingerprint -sha256` 输出一致
    var groups []string
    for i := 0; i < len(sha256); i += 2 {
        end := i + 2
        if end > len(sha256) { end = len(sha256) }
        groups = append(groups, sha256[i:end])
    }
    sha256 = strings.Join(groups, ":")
    serial = strings.ToUpper(hex.EncodeToString(cert.SerialNumber.Bytes()))
    expired = time.Now().After(cert.NotAfter) || time.Now().Before(cert.NotBefore)
    return
}
```

## 9. 风险与兼容

| 风险 | 缓解 |
|---|---|
| 旧版本前端缓存 `info.cert_*` 字段未变 → 升级后用户刷新前看不到新字段 | 旧字段全部保留向后兼容；新增字段为 optional，前端用 `info.public_anthropic_url || \`https://${info.agent_host}:${info.https_port}/${info.anthropic_path}\`` 兜底 |
| `agentPublicHost` 配置项缺省时回退 `agentProductListenAddr` | 与现有 `certDownloadInfoInterfaceHandle` 中 `host = "127.0.0.1"` fallback 行为一致 |
| `parseCertMeta` 解析失败时返回空字符串 | 前端相应字段渲染 `-`，不阻塞弹窗 |
| 新增 4 条接入地址占用 Modal 高度 | width 620 → 760；段落用 `<details>` 默认折叠（macOS 段除外，open=true） |
| 跨平台指引命令版本差异（CentOS 7 vs 8） | 命令旁注释提示；不在命令中做 shell 条件分支 |
| 双构建隔离被破坏 | 不引入管理员专属组件；构建后 `grep -l 'ManagerLogin\\|UserManage' ClientWeb/dist-user/` 必须为空 |
