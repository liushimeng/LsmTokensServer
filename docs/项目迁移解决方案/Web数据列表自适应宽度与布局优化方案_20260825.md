# Web 数据列表自适应宽度与布局优化方案（阶段 AC）

> 日期：2026-08-25
> 范围：管理员 Web（9101）与用户 Web（29001）双端共用前端（ClientWeb），纯前端改造，零后端接口改动。

## 1. 背景与问题

1. `/AIRouteManage` 智能路由管理页「智能路由数据列表」未占满窗口宽度，右侧大量留白；
2. 「目标源站列表」列部分记录 chip 序列过长，依赖横向滚动才能看全；
3. 所有子页面根容器 `.page { max-width: 1280px }`，宽屏浏览器下核心显示区域两侧留白明显；
4. `.data-table th, td { white-space: nowrap }` 导致任何一列内容过长即触发 `.table-wrap` 横向滚动。

## 2. 目标

- 内容区宽度自适应浏览器窗口（满宽展示，不留白），保留合理内边距；
- 数据表格默认无横向滚动：列宽自适应分配，长内容单元格自动换行（多行展示）；
- 超长"词元"（URL、API Key、Token 串）按 `overflow-wrap: break-word` 断行；
- 需要保持单行的列（操作按钮组等）支持列级 `nowrap` 声明；
- AIRouteManage「目标源站列表」chip 改为 flex 换行布局（`.chip-list`），完整展示全部源站；
- 双构建（dist-manager / dist-user）行为一致，移动端 ≤600px 卡片模式不受影响。

## 3. 改动点

### 3.1 index.css

| 类 | 改动 |
|---|---|
| `.page` | `max-width: 1280px` → `max-width: none; width: 100%; min-width: 0`（满宽自适应） |
| `.data-table td` | 默认 `white-space: normal; vertical-align: top; overflow-wrap: break-word`（允许换行，消除横向滚动根源） |
| `.data-table th` | 保持 `white-space: nowrap`（表头不折行） |
| 新增 `.data-table td.cell-nowrap` | 列级声明不换行（保留 nowrap 语义给操作列等） |
| 新增 `.chip-list` / `.ep-chip` | 源站 chip 列表：`display:flex; flex-wrap:wrap; gap:4px`；chip 样式从 AIRouteManage 内联 style 迁入全局类 |
| `.data-table td.wrap` | 保留兼容旧用法，去掉 420px 上限改为 `max-width: none` |
| 新增 `.op-btns`（桌面态） | 操作列按钮组 flex 换行，避免按钮被字符断行撑散 |

### 3.2 DataTable.jsx

- 列定义新增 `nowrap: true` 选项：渲染 td 时追加 `cell-nowrap` 类；
- 组件头注释同步更新。

### 3.3 AIRouteManage.jsx

- `renderEpList` 内联样式 chip 改为 `<div className="chip-list">` + `<span className="ep-chip">`（禁用源站加 `ep-chip-off` 修饰类）；
- 操作列 render 外层改 `<span className="op-btns">`（inline-flex 换行）。

### 3.4 全站自动受益（无需逐页修改）

`td` 默认可换行 + `.page` 满宽为全局样式，以下页面的长内容列（URL、模型名、Key、消息摘要等）自动获得自适应换行与满宽展示：
UserManage、DstEndPointManage、ModelInfo、ChatDialog、ChatAnalysis、ChatAnalysisTotal、ChatAnalysisSession、ChatAnalysisTask、ProtocolConvertAnalyzer、SpiderDataSource、SpiderDailyInfo、CleanupReport、AgentInfo。
