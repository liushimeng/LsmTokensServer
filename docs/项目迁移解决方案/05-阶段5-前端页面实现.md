# 阶段5：前端页面实现（React + Vite）

## 架构
- `ClientWeb/` 单工程双入口（或 MPA 多入口）：`apps/manager`（管理端，对应旧 9101）、`apps/user`（用户端，对应旧 29001）。
- 请求层统一封装（fetch/axios），支持 JWT 登录态、HTTPS。
- WebSocket 客户端封装对接 `/ws` 推送（chat_total 流式）。

## 页面迁移清单（自旧 `server_web_user_*` / `server_web_manager_*` 提取）

用户端：UserLogin、Home、AgentInfo、AiRoute、Analysis、ChatAnalysis、ChatSession/Task/Total、CleanupReport、DstEndpoint、ModelInfo、ProtocolConverter。
管理端：ManagerHome、AgentInfo、AiRoute、ChatAnalysis/Detail/Page/Total、CleanupReport、DstEndpoint、ModelInfo、User、ProtocolConverter。
爬虫页（旧 29002 MCP 相关/Spider）：Crawl、DailyInfo、DataSource。
公共：Header、Nav、Toolbar、各 Dialog（cert/git/readme/sourcecode/sysinfo/userlog/wiki）。

## 部署
- `npm run build` 产物输出 `dist/`；后端 `webserver` 包静态托管，或脚本复制到 ServerGo 静态目录。
- 路由使用 React Router；API 通过相对路径或配置的 baseURL 访问后端。

## 验收
- 每完成一组页面即 git 中文提交并可用浏览器访问验证（需端口切换或临时端口联调）。
