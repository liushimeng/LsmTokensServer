# 调用次数和 Token 数趋势 K 线图优化方案（v2 重做版）

- 阶段：v2.0.60 系列 / 阶段V 重做
- 文档时间：2026-08-26
- 适用范围：管理员 Web（9101）、用户 Web（29001）
  - `/ModelInfo` 模型信息页
  - `/AgentInfo` Agent 信息页

## 一、v1 实现的问题

| # | 问题 | 复现 |
|---|---|---|
| 1 | **Y 轴文字变形** | `viewBox` 用 `preserveAspectRatio="none"` 导致 SVG 字号随外层容器非等比拉伸/压缩；左轴 + 右轴标签字符被横向拉长 |
| 2 | **无区间缩放** | 用户无法聚焦某一时段细看；最长窗口 30 天只能"硬切" 4 个按钮 |
| 3 | **跨度不自适应** | 24h 用 24 个小时桶合理，720h 强制按天桶后画面过于稀疏；用户不能在小窗口看到分钟级、大窗口看到周/月级 |
| 4 | **轴标签冗余** | 同时显示 "count" 与 "tokens" 两套刻度 + "M/k" 单位缩写，用户信息密度过高 |

## 二、v2 目标

| # | 目标 | 度量 |
|---|---|---|
| G1 | 字号不变形 | SVG 改用 `preserveAspectRatio="xMidYMid meet"` 等比缩放；轴刻度改用**绝对像素**渲染（HTML 浮层），避免拉伸 |
| G2 | 滚轮缩放 | 鼠标在画布上滚轮 → 在鼠标 X 位置为锚点放大/缩小 X 轴；Ctrl/Cmd + 滚轮 → 同时缩放 Y 轴 |
| G3 | 左键框选 | mousedown 起点 → mousemove 拉框 → mouseup 落点 → 视图聚焦到选中区间 |
| G4 | 跨度自适应 | hours 区间 → 自动选择桶粒度：≤48h 小时桶；49h~14d 小时+天混合；15d~60d 天桶；>60d 周桶 |
| G5 | 文案精简 | 单一左 Y 轴 "调用次数" + 右 Y 轴 "Tokens"（去掉 "数" 字），紧凑数字 |

## 四、跨度自适应桶粒度（关键）

后端已返回 hours≤168 小时桶 + hours>168 天桶的混合格式。但**前端**展示时，根据**当前视图区间的实际跨度**重新选择"视觉桶粒度"——这是 v2 的关键改进：

| 当前视图小时跨度 | 显示粒度 | X 轴标签密度 | 后端请求 |
|---|---|---|---|
| ≤48h | 小时桶（每点 1h） | 每 6h 一标签 | 已按 hours 拉过 |
| 49h~168h（7d） | 小时桶 | 每 24h 一标签 | 已按 hours 拉过 |
| 169h~720h（30d） | 天桶（按 created_at 聚合成日总和） | 每天一标签 | 已按 hours 拉过 |
| 720h~4320h（180d，30d×6 缩放） | 周桶（按周聚合） | 每周一标签 | **需补后端 hours=4320 窗口** |

> 简化策略：v2 前端**只**对已加载的 points 做二次聚合（Go 端保持不变），即"按需重聚合"。当用户缩放到 >720h 时，前端按周聚合已加载的数据点（即便精度有限）。

为了"按需重聚合"，前端维护 `originalPoints`（后端原始返回）+ `displayPoints`（按视图跨度二次聚合）。

### 桶粒度切换算法

```js
function inferBucketSize(hourSpan) {
  if (hourSpan <= 48) return 'hour'
  if (hourSpan <= 720) return 'day'   // ≤30d 用天桶
  return 'week'                       // >30d 用周桶
}
```

## 五、Y 轴文字不变形方案

### 5.1 根因分析
- 当前 SVG `viewBox="0 0 720 280"` + `preserveAspectRatio="none"` → 容器宽高比变化时，文字随 X/Y 各自拉伸

### 5.2 方案：等比缩放 + 绝对定位轴文字
```jsx
<svg viewBox="0 0 720 280" preserveAspectRatio="xMidYMid meet">
  {/* 只画网格线 / 折线 / 区域填充：等比缩放 OK */}
  <line ... />
  <path ... />
</svg>
{/* 轴文字用 HTML 浮层：浏览器文字渲染不受 SVG 缩放影响 */}
<div className="y-axis-left">{countTicks.map(v => <span>{compactNumber(v)}</span>)}</div>
<div className="y-axis-right">{tokenTicks.map(v => <span>{compactNumber(v)}</span>)}</div>
```

**布局：**
- SVG `<g>` 留出 `padL = 0 / padR = 0`（文字外置）
- 外层 flex/grid 把左轴文字 / SVG / 右轴文字三列并排

### 5.3 字号精简
- 左轴："调用次数"，刻度 `1.2k / 3.4k / 5.6k`（单位`k`只在 ≥1000 时）
- 右轴："Tokens"，刻度 `1M / 3M / 5M` 或 `120 / 3.4k / 56k`
- 数字超过 4 位用紧凑格式（1.2k/3.4M）；4 位以内显示完整数字
- 工具提示固定显示完整数字（hover 浮窗不受限制）

### 6.3 鼠标滚轮 + 左键框选（KLineTrendChart 内部）

```js
// wheel handler
const onWheel = (e) => {
  e.preventDefault()
  const rect = svgRef.current.getBoundingClientRect()
  const x = (e.clientX - rect.left) / rect.width * innerW  // SVG 内坐标
  if (e.ctrlKey || e.metaKey) {
    // Y 轴缩放（不动 X）
    zoomY(e.deltaY < 0 ? 1.1 : 1/1.1)
  } else if (e.shiftKey) {
    // X pan
    panX(e.deltaY)
  } else {
    // X 轴 zoom，x 为锚点
    zoomXat(x, e.deltaY < 0 ? 1/1.15 : 1.15)
  }
}

// mouse drag handler
const onMouseDown = (e) => { brushStart = xOfEvent(e) }
const onMouseMove = (e) => { if (brushStart) updateBrush(xOfEvent(e)) }
const onMouseUp = (e) => {
  if (brushStart && Math.abs(brushEnd - brushStart) > 4) {
    commitBrush({ from: brushStart, to: brushEnd })
  }
  brushStart = null
}
```

## 九、风险与回退

| 风险 | 应对 |
|---|---|
| SVG 缩放后路径点采样精度 | 用 1 个 path + transform 处理缩放（不重算点）；客户端性能上限 ≈ 1k 点 |
| 滚轮事件未 preventDefault 导致页面滚动 | 在 `<div onWheel>` 上 `e.preventDefault()`（容器非事件） |
| 用户用触摸板平移时误触发滚轮 | shiftKey 检测 + 滚动方向判定 |
| 缩放后 X 轴标签过密 | 自动按可见点数 / N 计算采样密度（每 N=80px 一个标签） |
| 后端 hours 上限 720，缩放到 >720h 只能用聚合数据 | 前端按周聚合显示，提示"已按周聚合" |
