# Web 表格状态高亮与点击排序升级方案（2026-08-25）

## 1. 背景与目标

管理员 Web（9101）/ 用户 Web（29001）的列表页中，记录的「启用/禁用」状态仅靠 8px 状态圆点 + 文字表达，不够醒目；同时数据表格不支持点击表头排序。本次升级：

1. **状态行高亮**：禁用记录整行淡红背景 + 左侧红色标识条，启用记录淡绿背景，一眼区分。
2. **表头点击排序**：纯前端实现（不动后端接口），点击可排序列表头循环 升序 → 降序 → 取消，表头显示 ▲/▼ 指示。
3. **全站遍历**：所有带「启用/禁用」状态的表格统一应用行高亮；主要数据列表补齐可排序列。

## 2. 通用组件改造（ClientWeb/src/components/DataTable.jsx）

- 新增 props：
  - `rowClass(row)`：返回附加到 `<tr>` 的 className，用于状态高亮。
  - 列定义新增 `sortable: true`：表头变为可点击（`cursor:pointer`），内部维护 `{key, dir}` 排序状态。
- 排序比较器：数值列按数值比较，其余 `localeCompare('zh-CN')`；null/undefined 排末尾；渲染列可通过 `sortValue(row)` 提供取值函数（如「所属用户」按用户名而非 user_id 排序）。
- 卡片模式（≤600px）下排序表头不可见，排序仍生效于数据顺序。

## 3. 样式（ClientWeb/src/index.css）

```css
.data-table tr.row-disabled td { background:#fdf1f1; }
.data-table tr.row-disabled td:first-child { box-shadow: inset 3px 0 0 #ef4444; }
.data-table tr.row-enabled td  { background:#f4faf4; }
.data-table th.sortable { cursor:pointer; user-select:none; }
.data-table th.sortable:hover { color: var(--primary, #2563eb); }
```

hover 样式保持优先（禁用行 hover 回到常规 hover 色）。

## 4. 页面应用清单

| 页面 | 行高亮依据 | 可排序列 |
|---|---|---|
| DstEndPointManage（源站管理，双端） | `status != 1` → row-disabled，否则 row-enabled | ID、所属用户（按用户名）、平台、模型、协议、URL、状态 |
| UserManage（用户管理，管理端） | 用户 `status === 2` → row-disabled；嵌套模型表 `status === 2` 同理 | ID、用户名、状态、模型数 |
| SpiderDataSource（爬虫数据源） | `status !== 1` → row-disabled | ID、名称、平台、状态 |
| 其余分析页（ChatAnalysis 系列） | 无启用/禁用语义，不改高亮 | 已有各自分页/筛选，本次不动 |

操作列、复选框列不参与排序。
