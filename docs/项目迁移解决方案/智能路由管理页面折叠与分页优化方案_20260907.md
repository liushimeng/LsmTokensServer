# 智能路由管理页面折叠与分页优化方案

> 适用版本：v2.0.77+（前端双构建隔离方案之后）
> 涉及页面：管理员 Web（9101）与用户 Web（29001）的 `/AIRouteManage` 智能路由管理
> 涉及文件：`ClientWeb/src/pages/AIRouteManage.jsx`、`ClientWeb/src/components/DataTable.jsx`、`ClientWeb/src/i18n/locales/{zh-CN,en,ja}.json`、`ClientWeb/src/index.css`

## 一、背景与现状

`AIRouteManage` 页面核心列表控件 `DataTable` 已具备可折叠行（点击 ▶/▼ 切换）能力，并提供两种折叠摘要策略：

1. **`renderCollapsedRow`**（自定义跨列摘要行）：当前 AIRouteManage 已采用，自定义输出 ID / 用户 / 模型 / 源站摘要 / 操作按钮。
2. **`collapsedHiddenColumns`**（隐藏指定列）：旧方案，已在阶段 BU 移除。

但当前折叠摘要行存在以下问题，与产品需求不符：

| 序号 | 现状 | 需求 |
|---|---|---|
| 1 | 操作列同时显示 `对话` / `对话明细分析` / `汇总统计` / `编辑` / `删除` 5 个入口 | 删除 `对话` 与 `汇总统计` 按钮，保留 `对话明细分析` 并改为绿色背景以示强调 |
| 2 | 折叠摘要行只有 ID / 用户 / 模型 / 源站摘要 / 操作 5 项 | 折叠后必须显示 `协议` / `算法策略` / `汇总统计` / `最后成功记录` / `最后失败记录` 列数据，操作列内容折叠态必须隐藏 |
| 3 | 折叠摘要行元素换行宽松，窗口窄时溢出 | 折叠后内容尽量布局在一行内，长内容自动省略 |
| 4 | 分页状态已支持 localStorage 记忆 | 保持并增强：刷新按钮 / 刷新页面 / 重新加载都保留当前页与页大小 |
| 5 | `PAGE_SIZES = [10, 20, 30, 50, 100]`，`DEFAULT_PAGE_SIZE = 50` | 选项精简为 `[10, 20, 50, 100]`，默认 50（已符合，仅去除 30） |

## 二、设计目标

1. **操作列精简**：管理端/用户端操作列均只保留 3 个入口：
   - **编辑路由**（蓝色 btn-primary）
   - **对话明细分析**（绿色 btn-success，跳转 ChatAnalysis）
   - **删除路由**（管理端，红色 btn-danger；用户端不展示）

   `对话`（直接看对话流）和 `汇总统计`（ChatAnalysisTotal 概览）作为入口被移除，避免列表行过度拥挤；用户若有需求，可从对话明细分析页（ChatAnalysis）顶部时间筛选自由切换。

2. **折叠摘要行紧凑布局**：折叠态展示以下信息（按列优先级从左到右）：
   - ▶ 展开按钮
   - `#ID`
   - 所属用户（仅管理端）
   - 模型名
   - 协议徽章（Anthropic / OpenAI）
   - 算法策略标签（指定/稳定/经济）
   - 源站摘要（首条 + 剩余数量 + 悬停 tooltip 显示全部，与 CollapsibleList `single` 模式一致）
   - 汇总统计（`A:xx / O:xx`，0 隐藏对应方）
   - 最后成功记录（紧凑单行：状态 + 时间）
   - 最后失败记录（紧凑单行：状态 + 时间）

   操作列内容在折叠态隐藏；展开态恢复。

3. **单行布局**：CSS 弹性盒 + `flex-wrap: nowrap` + 子项 `overflow:hidden; text-overflow:ellipsis; white-space:nowrap`，保证折叠行高度稳定。窗口过窄时优先压缩摘要文本、保留主要徽章/标签。

4. **分页记忆**：保持既有 `lsm:airoute:page:{role}` localStorage 键，记录 `{ page, pageSize }`：
   - 刷新按钮调用 `loadRoutes()` 保留 `page` 与 `pageSize`；
   - 浏览器 reload 自动从 localStorage 恢复；
   - 切换页大小 → 自动跳回第 1 页（已有逻辑保留）；
   - 后端数据变动后路由数减少导致 `safePage` 自动收敛（已有 `Math.min(page, totalPages)`）。

5. **分页选项**：`PAGE_SIZES = [10, 20, 50, 100]`，`DEFAULT_PAGE_SIZE = 50`。

## 三、技术方案

### 3.1 操作列精简（`AIRouteManage.jsx`）

修改 `columns` 中 `key: 'actions'` 的 `render`，删除 `t('aiRouteManage.dialog')` 与 `t('aiRouteManage.summaryStats')` 两个 `<a className="btn btn-link">`，并将 `t('aiRouteManage.dialogAnalysis')` 改为 `btn-success`（绿色背景）。

修改前：

```jsx
<a className="btn btn-link" href={...}>{t('aiRouteManage.dialog')}</a>
<a className="btn btn-link" href={...}>{t('aiRouteManage.dialogAnalysis')}</a>
<a className="btn btn-link" href={...}>{t('aiRouteManage.summaryStats')}</a>
```

修改后：

```jsx
<a className="btn btn-sm btn-success" href={...}>{t('aiRouteManage.dialogAnalysis')}</a>
```

### 3.2 折叠摘要行内容扩展（`AIRouteManage.jsx`）

重写 `renderCollapsedRow`，按设计目标从左到右排版：
- 新增 `<span className="collapsed-stat">{汇总统计}</span>` 渲染 `A:xx / O:xx`
- 新增 `<span className="collapsed-last-success">{最后成功记录摘要}</span>`
- 新增 `<span className="collapsed-last-failure">{最后失败记录摘要}</span>`
- 操作区在折叠态仅显示 `编辑` 与 `删除`（保持现状，已隐藏 `对话`/`汇总统计` 入口）。

新增三个轻量渲染函数：
- `renderCollapsedStats(route)`：复用现有 stats 列逻辑，输出 `A:xx / O:xx` 紧凑形式；全 0 显示 `—`。
- `renderCollapsedLastRecord(route, kind)`：复用现有 `renderLastRecord`，去掉 `<span>` 中的多余空格，纯紧凑一行：`✓200 时间`，无数据时显示 `—`。
- `renderAlgoTag(route)`：输出 `algo-badge algo-{1|2|3}` 三色徽章（指定=蓝、稳定=紫、经济=橙），与展开态视觉一致。

### 3.4 分页选项精简（`AIRouteManage.jsx`）


### 3.6 后端接口

无需改动。本方案仅前端 UI/交互优化：
- `AIRouteManageInterface` (POST `{action:'list'|'list_endpoints'|'list_models'|...}`)
- `UserAIRouteInterface` (POST `{action:'list'|'list_endpoints'|'update'|'count_record_by_protocol'}`)

`list` 已返回 `endpoint_list` / `protocol_type` / `algorithm_strategy_type` / `last_success_*` / `last_failure_*` 字段，足够支撑折叠摘要行。

## 五、风险与回退

- **风险 1**：单行紧凑折叠在极窄屏（<640px）下溢出。  
  **缓解**：CSS `@media` ≤768px / ≤1024px 分级隐藏 last-success/last-failure 与 endpoints，保留关键徽章。

- **风险 2**：localStorage 中存在旧值 `pageSize: 30`，切换后无法匹配。  
  **缓解**：初始化时 `PAGE_SIZES.includes(s.pageSize)` 校验失败自动回退 `DEFAULT_PAGE_SIZE = 50`。

- **风险 3**：折叠态源站摘要的 tooltip（CollapsibleList `single` 模式）与同行其他元素的 z-index 冲突。  
  **缓解**：tooltip 默认相对父级定位（`position:absolute`），父级 `.collapsed-endpoints` 已设置 `position:relative`。

- **回退策略**：若用户反馈折叠行过于拥挤，仅需将 `renderCollapsedRow` 改回三段式（id + 模型 + 协议 + 源站）即可，不影响展开态与分页。
